# 付録：外部性と共通性の定式化 ─ 個人の合理性の総和と、全体の合理性

> **この付録の位置づけ**：[00 理論](../chapters/00_externality-and-commons.md) と [03 設計A：判断ルール](../chapters/03_it-materiality-proposal.md) の補足。本文の議論を簡単なモデルで書き下す。本文は数式なしで読めるように書かれており、この付録を読まなくても本文の理解に支障はない。
> **関連章**：[00 理論](../chapters/00_externality-and-commons.md)／[01 分析①：予算配分の層](../chapters/01_it-investment-market-failure.md)／[03 設計A：判断ルール](../chapters/03_it-materiality-proposal.md)

本文の中心的な主張は、「各主体は自らの視野の中で完全に合理的に判断しているにもかかわらず、全体としては望ましくない結果に至る」というものである。
これを式で表すと、**個人の最適条件を足し合わせたものが、全体の最適条件と一致しない**ということになる。外部性は、その二つの条件の**差として現れる項**である。

本付録では、外部性の三つの型についてこの差を確かめ（A〜C）、最後に「共通性」を判断に入れた後の式を示す（D）。

| 節 | 型 | 本文での扱い | 帰結 |
|---|---|---|---|
| A | コモンズの悲劇（負の外部性・共有資源） | 00 §03／01 症状③ | 過剰利用 |
| B | 公共財の過小供給（正の外部性） | 00 §04／01 症状① | 過小供給 |
| C | 異時点間の外部性 | 01 症状② | 過剰蓄積（先送り） |
| D | 共通性を入れた後の判断 | 03 §03〜§05 | ─ |

## A　コモンズの悲劇 ─ 個人の合理性の総和は、全体の合理性と一致しない

N 人の牛飼いが一つの牧草地を共有しているとする。

| 記号 | 意味 |
|---|---|
| $x_i$ | 牛飼い $i$ が放牧する牛の頭数 |
| $X = \sum_{i=1}^{N} x_i$ | 牧草地全体の頭数 |
| $v(X)$ | 牛1頭あたりの価値。頭数が増えるほど1頭あたりの牧草が減るため、逓減する（$v'(X) < 0$） |
| $c$ | 牛1頭あたりの飼育費用 |

**① 個人の合理性**

牛飼い $i$ の利益は $\pi_i = x_i\,v(X) - c\,x_i$ である。1頭増やすことが得になる限り増やすので、各人は次の条件が成り立つところまで頭数を増やす。

$$
v(X) + x_i\,v'(X) = c
$$

左辺第2項は、牧草の減少によって**自分の牛**の価値が下がる分である。他の牛飼いの牛が受ける損は、この計算に入っていない。

**② 個人の合理性の総和**

全員が同じ計算をすると、対称な均衡（$x_i = X/N$）では次が成り立つ。これを満たす頭数を $X^N$ とする。

$$
v(X^N) + \frac{X^N}{N}\,v'(X^N) = c
$$

**③ 全体の合理性**

牧草地全体の利益 $W = X\,v(X) - c\,X$ を最大にする頭数 $X^*$ は、次を満たす。

$$
v(X^*) + X^*\,v'(X^*) = c
$$

**④ 両者の差が外部性である**

②と③を比べると、個人の計算からは次の項が抜けている。

$$
-\frac{N-1}{N}\,X\,v'(X) \;>\; 0
$$

これは、ある牛飼いが1頭増やしたときに**他の牛飼いの牛に与える損**である。00 §03 の「費用が共有化される」を式にしたものにほかならない。各人は牧草減少の損の $1/N$ しか計上しないため、均衡の頭数は最適を上回る（$X^N > X^*$）。

**数値例**

1頭あたりの価値が線形に逓減する最も単純な場合（$v(X) = a - bX$）では、次のようになる。

$$
\frac{X^N}{X^*} = \frac{2N}{N+1}, \qquad \frac{W^N}{W^*} = \frac{4N}{(N+1)^2}
$$

| 牛飼いの数 $N$ | 均衡の頭数（最適＝1） | 全体の利益（最適＝100%） |
|---|---|---|
| 1 | 1.0 | 100% |
| 3 | 1.5 | 75% |
| 10 | 1.8 | 33% |
| ∞ | 2.0 | 0% |

利用者が増えるほど、一人が負う損は小さく見え、頭数は増え、全体の利益は失われる。$N \to \infty$ では、1頭あたりの価値が費用に等しくなるまで（$v(X) = c$）頭数が増え、資源から得られる利益は完全に消える。これはオープンアクセス資源の標準的な帰結である（Gordon, 1954）。

**処方箋との関係**

00 §05 の処方箋は、いずれも**抜けている項を個人の計算に戻す（内部化する）**か、**計算そのものを変える**方法として読める。たとえばピグー税では、牛1頭あたり $t = -(X - x_i)\,v'(X)$ を課す。すると個人の条件 $v(X) + x_i\,v'(X) = c + t$ は、全体の条件③と一致する。Ostrom が示した自主的統治の諸条件（監視・段階的制裁など）も、利得の構造を変えて「控えること」を個人にとって合理的にする仕組みである。

## B　公共財の過小供給 ─ 誰も種を蒔かない

A が「牧草を食い尽くす」問題なら、B は「そもそも誰も種を蒔かない」問題である（00 §04）。便益が全員に及び、他者の利用を排除できない共通の基盤を考える。

| 記号 | 意味 |
|---|---|
| $g_i$ | 主体 $i$ が基盤に投じる量 |
| $G = \sum_{i=1}^{N} g_i$ | 基盤の整備水準 |
| $b(G)$ | 各主体が基盤から得る便益。整備が進むほど増えるが、増え方は逓減する（$b' > 0,\ b'' < 0$） |
| $c$ | 整備1単位あたりの費用。投じた主体が負担する |

**① 個人の合理性**

主体 $i$ の利益は $\pi_i = b(G) - c\,g_i$ である。自分が1単位投じて得られるのは、**自分の**便益の増分 $b'(G)$ だけなので、各人は次の条件まで投じる。

$$
b'(G) = c
$$

**② 個人の合理性の総和**

この条件は主体ごとの取り分に依らず、$G$ だけで決まる。したがって、誰かが条件を満たす水準 $G^N$ まで整備すれば、他の主体は1単位も追加しない（ただ乗り）。

$$
b'(G^N) = c
$$

全員を合わせても、**1主体が単独で整備する量にとどまる**。01 症状①の「やむなく着手する部門が現れても、自部門に必要な範囲でしか作らない」は、この式の言い換えである。

**③ 全体の合理性**

全体の利益 $W = N\,b(G) - c\,G$ を最大にする水準 $G^*$ は、次を満たす。

$$
N\,b'(G^*) = c
$$

全員の限界便益の**合計**が費用に等しくなる水準である（Samuelson 条件）。

**④ 両者の差が外部性である**

個人の計算からは、次の項が抜けている。

$$
(N-1)\,b'(G) \;>\; 0
$$

これは、自分が整備したときに**他の主体が得る便益**である。$b'$ は逓減するので、$G^N < G^*$ となる。

**数値例**

便益が対数的に逓減する場合（$b(G) = \beta \ln G$）、$G^N = \beta/c$、$G^* = N\beta/c$ となる。

| 主体の数 $N$ | 均衡の整備水準（最適に対する割合） |
|---|---|
| 1 | 100% |
| 3 | 33% |
| 10 | 10% |

主体が増えるほど全体の必要量は増えるが、供給は1主体分のまま変わらない。集団が大きいほどただ乗りが深刻になるという、Olson (1965) の指摘に対応する。

**一括投資の場合**

IT基盤の多くは、少しずつ積み増すものではなく、「作るか、作らないか」の一括投資である。総費用を $K$、各主体が得る便益を $b$ とすると、次のようになる。

| | 作るべき条件 |
|---|---|
| 個人の合理性 | $b > K$（自分の便益だけで費用を賄える） |
| 全体の合理性 | $N\,b > K$（全員の便益の合計が費用を上回る） |

$b < K < N\,b$ の範囲にある基盤は、全体としては作るべきなのに、**どの主体も起案しない**。01 症状①の「『全社に必要だ』と全員が認めながら、誰も予算を出さない状態」は、この範囲にある案件である。

## C　異時点間の外部性 ─ 費用は将来へ

標準からの逸脱、個別最適の実装、EOL の延命は、いずれも「今の節約」と「将来の費用」の交換である（01 症状②）。

| 記号 | 意味 |
|---|---|
| $S$ | 逸脱・先送りによって今期に節約できる費用（速さ・安さ） |
| $F$ | それによって $t$ 年後に発生する費用（複雑性・保守費・移行費） |
| $\delta$ | 割引因子（$0 < \delta \le 1$） |
| $\theta$ | 将来費用のうち、今期の判断者自身が負う割合（$0 \le \theta \le 1$） |

**① 個人の合理性**

判断者が負うのは将来費用の一部 $\theta F$ だけである。残りは、共通基盤を通じて他部門へ、あるいは予算年度や担当者が変わった後の組織へ回る。したがって、次の条件で逸脱・先送りを選ぶ。

$$
S > \theta\,\delta^{t} F
$$

**② 全体の合理性**

全体としては、将来費用のすべてを計上して判断すべきである。

$$
S > \delta^{t} F
$$

**③ 両者の差が外部性である**

$$
(1-\theta)\,\delta^{t} F
$$

$\theta\,\delta^{t}F < S < \delta^{t}F$ の範囲では、逸脱・先送りは個人には合理的だが、全体には損である。

特に、判断の視野が単年度の予算に閉じている場合、予算年度を越える費用は実質的に $\theta \to 0$ として扱われる。すると $S > 0$ でありさえすれば先送りが選ばれ、毎年同じ判断が繰り返される。将来費用は累積し、回避不能になった時点で緊急・高コストの対応となる（01 症状②）。

## D　共通性を入れた後の判断

### D-1　三つの型に共通する構造

A〜C は、いずれも次の形にまとめられる。ある主体 $i$ が案件 $k$ について判断するとき、

$$
V^{k} = V_i^{k} + E^{k}
$$

| 記号 | 意味 | 本文との対応 |
|---|---|---|
| $V^{k}$ | 全体にとっての価値 | ─ |
| $V_i^{k}$ | 判断者（自部門・今期）にとっての価値 | 軸1 事業価値、軸2 リスク低減・法規制対応（03 §03） |
| $E^{k} = E^{k}_{+} - E^{k}_{-}$ | 判断者の計算の外にこぼれる価値 | 外部性 |
| $E^{k}_{+}$ | 他の主体・将来にこぼれる便益 | B の $(N-1)\,b'$、C の回避される将来費用 |
| $E^{k}_{-}$ | 他の主体・将来にこぼれる費用 | A の $-\frac{N-1}{N}Xv'$、C の $(1-\theta)\,\delta^{t}F$ |

共通性を入れる前の判断規則は、**$V_i^{k} > 0$ なら採択し、判断者の予算で支払う**、である。全体として望ましい規則（$V^{k} > 0$ なら採択）とは、二つの領域でずれる。

| 領域 | 状態 | 型 | 帰結 |
|---|---|---|---|
| ① $V_i^{k} \le 0 < V^{k}$ | 全体には必要だが、判断者には割に合わない | B、C（EOL更新など） | 過小供給・放置 |
| ② $V_i^{k} > 0 \ge V^{k}$ | 判断者には得だが、全体には損 | A、C（逸脱） | 過剰利用・過剰蓄積 |

### D-2　軸3（共通性）は、$E^{k}$ の推定である

03 §03 の軸3「共通性・持続性」は、判断者の計算から抜けている $E^{k}$ を、判断の場に載せるための推定値 $\hat{E}^{k}$ である。

| 段階 | 推定の方法 | 式の上での意味 |
|---|---|---|
| PHASE 1（初年度） | 6要素を見たうえで、Q1 基盤性・Q2 負債の2問に Yes／No で答える | $E^{k}$ の**符号**だけを見る。Q1 は $E^{k}_{+}$（他の何かが困るか）、Q2 は C の将来費用（将来の費用が増えるか）にあたる |
| PHASE 2（次年度〜） | 6要素ごとの程度を、台帳を根拠に評価する（基盤性：受益範囲・つながり・前提依存／負債：保守期限・標準からの逸脱・重複と個別運用） | $E^{k}$ の**大きさ**を推定する。受益範囲は $N$、つながり・前提依存は $E^{k}_{+}$、保守期限は C の $F$、標準からの逸脱・重複と個別運用は $E^{k}_{-}$ にあたる |

$\hat{E}^{k}$ を判断者自身に申告させると、救済の可否が申告値に依存する以上、$\hat{E}^{k} = E^{k} + (\text{正のバイアス})$ となる（01 症状④）。03 が「申請者には事実 $z^{k}$ だけを求め、推定 $\hat{E}^{k} = f(z^{k},\ \text{台帳})$ は IT部門が行う」とするのは、このバイアスを構造的に取り除くためである。

### D-3　予算への接続 ─ 判断主体の差し替えによる内部化

03 §05 の予算プロセスは、次の3段の判断規則として書ける。

| 段 | 判断の場 | 対象 | 採択の条件 |
|---|---|---|---|
| 1 | 事業部門予算 | 申請された案件 | $V_i^{k} > 0$（従来どおり） |
| 2 | 救済枠（IT枠） | 段1の不採択プール $\{k : V_i^{k} \le 0\}$ | $V_i^{k} + \hat{E}^{k} > 0$。IT枠 $B_{IT}$ の範囲内で、優先度の高い順に採択する |
| 3 | IT起案枠 | どの部門も申請しない一括投資（B の $b < K < Nb$） | $\sum_{j} b_j > K$ |

ここで重要なのは、**事業部門の計算 $\pi_i$ そのものは変わっていない**ことである。ピグー税のように、抜けている項を判断者の損得に上乗せしているわけではない。代わりに、ずれが生じる領域の判断を、$E^{k}$ を目的に含む別の主体（共通層のオーナーとしての IT部門）に移している。**判断主体の差し替えによる内部化**である。

03 §05 が「支払うのが事業部門である限り、『うちは払わない』が彼らの合理的判断であり続ける」と述べるのは、この点による。$\hat{E}^{k}$ を測っても、それを評価表に書き足すだけでは段1の条件 $V_i^{k} > 0$ は変わらない。段2・段3という別の判断の場と予算があってはじめて、$\hat{E}^{k}$ が判断を左右する。

### D-4　どこまで全体の最適に近づくか

| 型 | 03 の打ち手 | 式の上での到達度 |
|---|---|---|
| B 公共財の過小供給 | 段3 IT起案枠 | 起案枠があれば、$b < K < Nb$ の案件に供給主体が立つ。枠がなければ、段2には現れないため解けない |
| C 異時点間の外部性（放置側） | 段2 救済枠（Q2） | 領域①の案件は、$\hat{E}^{k}$ が十分に大きければ救済される |
| C 異時点間の外部性（逸脱側）、A コモンズの悲劇 | PHASE 2 の標準からの逸脱、03 §05 ステップ4 の全社での優先度議論、ShowBack（D-5） | **部分的**。救済・起案の仕組みは領域①（足りない側）に働くもので、領域②（やりすぎ側）の案件を止める働きは弱い |

全体の最適 $\{k : V^{k} > 0\}$ との残差は、次の三つから生じる。

- **枠の制約**：$V_i^{k} + \hat{E}^{k} > 0$ でも、$B_{IT}$ を超えた分は採択されない。枠の大きさが、最適への近さを決める（03 §06「実績を根拠に、共通層予算枠の拡大を要求する」）。
- **推定の誤差**：PHASE 1 は符号しか見ないため、$\hat{E}^{k}$ と $E^{k}$ のずれによる誤判定が残る。判定理由を記録し、PHASE 2 で大きさの推定に移る。
- **領域②への打ち手の弱さ**：A の型（共有資源の過剰利用）は、救済・起案の仕組みでは解けない。この残差への打ち手は、D-5 で扱う。

### D-5　共有資源の利用 ─ ShowBack は行い、ChargeBack は行わない

A の型を式どおりに内部化するなら、利用1単位あたり $t = -(X - x_i)\,v'(X)$ を利用部門に課金すればよい（A の「処方箋との関係」）。これが ChargeBack（内部課金）にあたる。本フレームワークはこれを採らず、**ShowBack（利用量と費用の部門別可視化）**にとどめる。

| | ChargeBack（内部課金） | ShowBack（可視化） |
|---|---|---|
| 式の上での働き | $\pi_i$ に $-t\,x_i$ を加え、個人の条件を全体の条件③に一致させる | $\pi_i$ は変えない。各部門の利用量 $x_i$ と、それが全体に与える費用を観測可能にする |
| 対応する処方箋 | ピグー税（00 §05） | Ostrom の成立条件「利用状況が監視され、可視化されていること」（00 §05） |

ChargeBack を採らない理由は、次の三つである。

- **B の型を悪化させうる。** 共通基盤の利用は、A の型（使えば他者の取り分が減る）であると同時に、B の型（集約するほど全体の便益が増える）でもある。利用に課金すると、部門は共通基盤を離れて個別の基盤を持つ方向に動きうる。これは C の型の「標準からの逸脱」を促し、$E^{k}_{-}$ を増やす。
- **$t$ を正しく測れない。** 課金額 $t$ は限界的な外部費用であり、PHASE 1 の推定精度（符号のみ）では定められない。誤った $t$ は、別の歪みを生む。
- **取引費用が大きい。** 予算を事業部門が保有する構造では、課金は部門間の予算移転と、その交渉を伴う。これは Coase が指摘した「取引費用が高ければ失敗する」条件にあたる（00 §05）。

ShowBack は $\pi_i$ を変えないため、それだけでは個人の条件は全体の条件に一致しない。役割は、**$x_i$ を観測可能にし、03 §05 ステップ4 の全社での優先度議論と PHASE 2 の判定で利用量を根拠に議論できる状態を作る**ことにある。利用量が見えなければ、割当も、利用ルールの設計も始められない。

### まとめ ─ 共通性の導入前と導入後

| | 導入前 | 導入後 |
|---|---|---|
| 判断に入る価値 | $V_i^{k}$ のみ | $V_i^{k}$ ＋ $\hat{E}^{k}$（IT部門が推定） |
| $E^{k}$ を判断する主体 | いない | IT部門（共通層のオーナー） |
| $E^{k}$ に支払う予算 | ない | 救済枠（段2）・IT起案枠（段3） |
| 事業部門の損得計算 | $\pi_i$ | $\pi_i$（変わらない） |
| 内部化の方法 | ─ | 判断主体の差し替え |
| 共有資源の利用量 | 見えない | ShowBack で可視化（課金はしない） |

共通性とは、**個人の合理性の総和と全体の合理性の差 $E^{k}$ を、測定し、判断する主体と予算を与えて、判断に足し戻すための項**である。
