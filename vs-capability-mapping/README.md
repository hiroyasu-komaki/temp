# バリューストリーム×ケイパビリティマップ

バリューストリーム（VS）ごとに、ケイパビリティ・アプリケーション・情報オブジェクト（データ）までを1つのExcelにまとめた参照モデルです。VSごとにフォルダを分けています。各VSは**それぞれ独立したプロジェクト**で、互いの関係は扱いません。

## VS一覧

| フォルダ | VS（L1） | 種類 | 対象・制度の基準 |
|---|---|---|---|
| `Target-to-Patients/` | Target-to-Patient | コア（社外に価値を届ける） | 希少疾患向け新規バイオ医薬品（抗体医薬）／米国（FDA・BLA・21 CFR） |
| `Hire-to-Retire/` | Hire-to-Retire | 支援型（社内に価値を届ける） | 日本の事業会社（正社員中心、新卒・経験者採用、月給制）／日本（労基法・安衛法・社会保険・税法・番号法ほか） |
| `Procure-to-Pay/` | Procure-to-Pay | 支援型（社内に価値を届ける） | 日本の事業会社（直接材・間接材・役務、月末締め・振込払い）／日本（取適法・フリーランス法・インボイス・電帳法・J-SOXほか） |
| `IT Management/` | Manage IT / Digital Solutions | 支援型（社内に価値を届ける） | 日本の製薬会社（GxPシステムを持つ、内製と外部委託の併用）／日本（GMP省令・ER/ES指針・CSVガイドライン・個人情報保護法・J-SOX・取適法ほか）。L2はIT4ITの4つのバリューストリーム |

フォルダ名とVS名が異なるもの：`Target-to-Patients/`（VS名はTarget-to-Patient）、`IT Management/`（VS名はManage IT / Digital Solutions）。

## 設計ルール（共通）

- **1行1項目**：L1〜L4列の「●」でその行のレベルを表す。
- **正本の所在**：VSとケイパビリティの関係は「VS×ケイパビリティ関係」シートが正本。VS×ケイパビリティのマトリクスはそこから数式で集計するため直接入力しない。
- **入力・出力情報が先**：VS L4の入力情報・出力情報が正本。情報オブジェクトはそれを取りまとめて一覧化したもの。
- **アプリケーションは種類の単位**：現状のシステム名との対応は別の工程で行う。
- **ケイパビリティ定義は独立**：定義にはVSなど他の要素との関係を載せない。評価（成熟度）の粒度はL2。
- **灰色の列は数式**：編集しない。
