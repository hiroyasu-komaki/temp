## 1. 業務用語

## 2. 会議体・組織・役割

| 名称 | 略称 | 構成・所属 | 役割 | 定義の出典 |
|---|---|---|---|---|
| Tier1 | | C-suite | 基準額を超える案件の優先順位（年次）と、随時のIntakeの優先度を決める | [憲章](../rules/02-charter.docx) 別表1 |
| Tier2 | | C-suiteの1つ下のレイヤのシニアマネジメント | 基準額以下の案件の優先順位（年次）と随時のIntakeの優先度、決裁の振り分け、実行計画の承認・否認を決める | [憲章](../rules/02-charter.docx) 別表2 |

| IT投資委員会事務局 | 事務局 | IT部門 ポートフォリオ・IT投資チーム | IntakeFormと実行計画の受付、Tier1・Tier2の運営、Tier3の招集の依頼、承認会議（ローカル）への委任の通知、決定の記録と通知 | [憲章](../rules/02-charter.docx) 第5条・第6条 |
| 機能の責任者 | | （TBD: 機能の責任者の役職） | IT投資ガバナンスの成果に責任を負い、運営の方針を決める | [憲章](../rules/02-charter.docx) 第5条 |
| 起案者 | | IT投資案件の案件担当者 | IntakeFormと実行計画を提出し、決定を受けて案件を進める | [憲章](../rules/02-charter.docx) 第5条 |
| Tier3の主催者 | | EAの統括責任者と各領域責任者 | Tier3を運営し、推奨案をTier2に報告する | [憲章](../rules/02-charter.docx) 第5条 |
| 承認会議（ローカル） | | 起案者の所属部門（事業部門またはIT部門）の承認会議 | Tier2が決裁を委ねた案件について、実行計画の承認・否認を決め、結果を事務局に報告する | [憲章](../rules/02-charter.docx) 第5条 |
| 起案者の所属部門 | | 事業部門またはIT部門 | PPMボードの通知を受け、起案者に実行計画の作成・提出を依頼する | [憲章](../rules/02-charter.docx) 第5条 |

| PPMボード | | | 優先順位・優先度が付いた案件を管理し、起案者の所属部門（事業部門またはIT部門）に実行計画の作成・提出（提出期限を含む）を通知する。承認後の効果を確認する | [憲章](../rules/02-charter.docx) 第5条 |
| ファイナンス部門 | | | 年次のIT投資予算を提示する | [憲章](../rules/02-charter.docx) 第5条 |

## 3. 略語

| 略語 | 正式名称 | 意味 |
|---|---|---|
| C-suite | Chief-level executives | CEO・CFO・CIOなど、最高責任者の層の経営層 |
| DoA | Delegation of Authority | 決裁権限表 |
| EA | Enterprise Architecture | 業務・データ・アプリケーション・技術の全体の構造と、その設計の原則 |
| PPM | Project Portfolio Management | 案件の集合を管理すること。本書ではPPMボードを指す |

## 4. 使い分け

| 区別すべき語 | 使い分け |
|---|---|
| 「優先順位」と「優先度」 | 優先順位＝年次の会議で、案件どうしを比べて付ける順位。優先度＝随時のIntakeで、実行計画の審議に進めてよいかの判断（あり／なし） |
| 「優先順位の審議」と「実行計画の審議」 | 優先順位の審議＝年次のIT投資予算をどの順で使うかを決める（Tier1・Tier2）。実行計画の審議＝優先順位・優先度が付いた案件の進め方を承認・否認する（Tier2） |
| 「審議」と「推奨」 | 審議＝会議体が決定する（Tier1・Tier2）。推奨＝Tier3が意見をまとめてTier2に報告する（決定しない） |
| 「起案者」と「起案者の所属部門」 | 起案者＝IntakeFormと実行計画を提出し、事務局の連絡を受ける案件担当者（個人）。起案者の所属部門＝案件を実行する組織 |
| 「ICTB（ローカル）」と「承認会議（ローカル）」 | ICTB（ローカル）＝旧制度で、単一の国・地域に閉じた案件の実行計画を承認した会議体（Tier2に置き換わる）。承認会議（ローカル）＝起案者の所属部門（事業部門またはIT部門）の承認会議で、Tier2が決裁を委ねた案件だけを承認する |
| 「決める」と「運営する」 | 決める＝会議体が優先順位・優先度・実行計画の可否を決定する。運営する＝事務局が受付・会議の準備・記録・通知を行う（事務局は決めない） |

## 5. 旧制度の用語との対応

| 旧用語 | 新用語 | 補足 |
|---|---|---|
| DIB | Tier1 | DIB相当の会議体 |
| ICTB（ローカル／グローバル） | Tier2 | ICTB相当の会議体 |
| — | Tier3 | 新設 |
| 事業部門内の承認会議 | 承認会議（ローカル） | Tier2が決裁を委ねた案件だけを承認する。事業部門とIT部門のどちらが起案した案件も対象 |
