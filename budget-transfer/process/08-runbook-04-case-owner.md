## 1. 概要

### 1.1 目的

担当BP（普段からファンクションの窓口を務める GDS のメンバー）が、担当する案件の移管を、普段の業務として進めるための手順を定める。全体のタスクと分担は [Runbook 全体編](./08-runbook-00-overview.md) に定める。

### 1.2 対象範囲

| 対象 | 対象外 |
|---|---|
| 移管対象の予算の特定と移管元との合意、予算シートへの転記とステータスの更新、契約・発注などの業務の引き継ぎ、取得予定・将来取得の案件の特定、11月末の完了目処の報告 | 移管の稟議（S&G編）、固定資産の会計処理（財務経理・S&G）、移管の後の間接業務そのもの（ベンダーマネジメント担当・事務担当） |

### 1.3 関係者

| 関係者 | この手順での関わり |
|---|---|
| カウンターパート | ヒアリングシートに答え、引き継ぎの時期を協議する |
| 移管元の責任者 | 移管対象の予算に合意する |
| S&G（FinanceBP） | 予算シートを提示し、全体を把握する。固定資産の案件の連絡と、完了目処の報告を受ける |
| ベンダーマネジメント担当・事務担当 | 引き継ぎで相談を受け、移管の後に契約の管理と事務手続きを担う |

### 1.4 責任（RACI）

担当BP のタスクの分担は、[Runbook 全体編](./08-runbook-00-overview.md) §3 を正とする。担当BP は B-01〜B-06 の A/R を持つ。B-01〜B-04 は依存関係がなく、同時に進める。

### 1.5 承認の依頼

担当BP が承認を依頼する事項はない。移管対象の予算は移管元と合意し、その結果を予算シートに書く。移管の稟議は S&G が申請する。

### 1.6 進捗の記録のしかた

報告書は作らない。担当する案件のステータスを予算シートで随時更新すれば、S&G が随時確認する。報告するのは、11月末の完了目処だけである。

### 1.7 12月末の完了の定義（担当BP から見た到達点）

| 区分 | 完了の定義 | 予算シートでの表し方 |
|---|---|---|
| 経費予算 | ① 移管対象の予算が、移管元と合意されている | ステータス「合意済み」 |
| | ② 移管対象の予算が、予算シートに漏れなく記載されている | 対象外は「対象外」、追加分は追記 |
| | ③ 移管対象の予算に紐づく業務の引き継ぎを開始している | ステータス「引継ぎ開始」 |
| 固定資産 | ① 取得予定・将来取得の案件が特定されている | 「固定資産」シートの行 |
| | ② 既存資産は移さないことを移管元と確認している | 「移管元」シートの既存資産を移さないことの確認日 |

業務の引き継ぎの完了、契約の名義変更、請求書の宛名の変更は、12月末の完了の定義に含めない。

## 3. 手順

### 3.1 ヒアリングシートを基に、移管対象の予算を特定し、移管元と合意する（B-01）

1. カウンターパートと、ヒアリングシートで次のことを確かめる。
   - 移管する予算（経費予算）と、それに紐づく契約
   - 移管の後に引き継ぐ業務（予算管理・契約管理・発注・支払）
   - 移管の後の報告・相談の方法
   - それぞれの時期（年内に発注が必要な案件があるか）
2. 設備投資の予算、システムと関係のない予算は対象外とする（憲章 第8条）。外部性・共通性・契約期間で、移管するかどうかは変わらない。
3. 移管対象の予算を、移管元の責任者と合意する。
4. ヒアリングシートの記録と受け取った資料は、各ファンクションと GDS の双方が編集できる既存の SharePoint フォルダに置く。

### 3.2 予算シートに転記する（B-02）

1. S&G が提示した予算シート（予算移管シート「予算一覧」）の、担当する案件の行を確かめる。
2. 予算区分とシステム関連を記入する。移管判定（自動）が「移管」「対象外」「判定保留」のどれになるかを確かめる。
3. 移管の対象ではない行は除外する（ステータスを「対象外」にする。行は消さない）。
4. 予算シートにない移管対象は、行を追記する（行の由来を「追記」にする）。投資予算と経費予算が混在する案件は、行を分ける。

### 3.3 ステータスを随時更新する（B-03）

1. 担当する案件が憲章 第10条の条件を満たしたら、その都度ステータスを更新し、更新日を記入する。
2. 「確認（自動）」に表示が出たら、ステータスか入力を見直す。S&G から見直しの依頼を受けたときも同じ。

| ステータス | 更新するとき |
|---|---|
| 確認中 | ヒアリングシートでの確認を始めたとき |
| 合意済み | 移管対象の予算を移管元と合意し、予算シートに記載したとき |
| 引継ぎ開始 | 紐づく業務の引き継ぎを始めたとき |
| 要協議 | 12月に間に合わない見込みになったとき |
| 対象外 | 移管の対象ではないと確かめたとき |

### 3.4 契約・発注などの業務を引き継ぐ（B-04）

1. 引き継ぎの開始時期は、カウンターパートと協議して決める。S&G への報告は要さない。
2. 業務マニュアル・契約書・過去の記録を基に、付録「引継ぎのめやす」に沿って受け手（ベンダーマネジメント担当・事務担当）に引き継ぐ。
3. 年内に発注が必要な案件は、予算移管を待たずに、可能な範囲で手続きを始める。
4. 契約の名義変更と請求書の宛名の変更は、適切な時期に行えばよく、予算移管と同時である必要はない。
5. 引き継ぎを始めたら、ステータスを「引継ぎ開始」にする。
6. GxP 対象の業務は、品質保証部門が定める SOP・手順に従い、手順の変更が要る場合はカウンターパートと調整して進める。

### 3.5 取得予定・将来取得の案件を特定し、FinanceBP に伝える（B-05）

1. カウンターパートと、次の案件があるかを確かめる（憲章 第12条）。
   - 取得予定：移管の時点で構築中で、移管の後に本勘定へ振り替えるもの
   - 将来取得：移管の後に着手する IT投資
   - 既存資産の改修：移管の後に、既存資産を改修するもの
2. 特定した案件を予算移管シート「固定資産」に書き、FinanceBP（S&G）に伝える。
3. 既存資産（償却中・簿価ゼロを含む）と長期前払費用は移さないことを移管元と確認し、予算移管シート「移管元」の確認日に記入する。

### 3.6 完了目処を報告する（B-06）

1. 11月末に、担当する案件ごとの完了目処（12月第1週に作業を終えられるか）を、「予算一覧」の完了目処の列に記入して S&G に報告する。
2. 12月に間に合わない案件は、ステータスを「要協議」にし、理由と見込みを備考に書いて S&G と協議する。

## 4. 例外対応

| 状況 | 一次対応 | 相談先 |
|---|---|---|
| 12月に間に合わない見込みの案件がある | ステータスを「要協議」にし、理由と見込みを書く | S&G |
| 移管元が移管対象の予算に合意しない | 懸念・条件を聞き取り、備考に書く。移管するかどうかは変わらないことを説明する | S&G |
| カウンターパートが決まらない、連絡がとれない | 移管元の責任者に依頼する | S&G |
| 予算区分（投資か経費か）が判断できない | 判定保留のまま、論点を備考に書く | S&G |
| 年内に発注が必要な案件がある | 予算移管を待たずに、可能な範囲で手続きを始める | （報告は不要） |

## 付録 引継ぎのめやす

業務の引き継ぎを進めるときのめやす。開始の条件ではなく、時期と進め方はカウンターパートと協議して決める。

### 付録1 受け手の対応表

| 引き継ぐ業務 | 移管の後の受け手 |
|---|---|
| 契約管理（締結・更新・変更・解約、委託先の管理） | ベンダーマネジメント担当 |
| 予算管理（計上・執行の管理） | 事務担当 |
| 発注・支払 | 事務担当 |

### 付録2 受け取るもの

| もの | 内容 |
|---|---|
| 業務マニュアル | 予算管理・発注・支払の手順、委託先への指示の方法 |
| 契約書（写し） | 契約の条件、期間、自動更新、解約予告、相手先の請求の窓口 |
| 過去の記録 | 発注・検収・支払の記録、委託先からの報告書 |

### 付録3 契約の名義変更と請求書の宛名の変更

移管の時点で契約について手続きをする必要はない。名義（署名者）の変更は次回の更新のときなど適切な時期に、請求書の宛名の変更はベンダーマネジメント担当が相手先に連絡して行う。
