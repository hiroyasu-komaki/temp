## 1. 概要

### 1.1 目的

予算移管の全てのタスクを1つの表で見られるようにし、登場人物の全員について分担（RACI）を定める。各タスクの手順は、役割別の Runbook に定める。

| 文書 | 対象 |
|---|---|
| この文書（全体編） | 全体のタスク一覧と、全ての登場人物を含む RACI。分担は、この文書の §3 を正とする |
| [Runbook S&G編](./08-runbook-01-transfer-lead.md)（BTR-P-08-01） | S&G のタスク（S-） |
| [Runbook 担当BP編](./08-runbook-04-case-owner.md)（BTR-P-08-04） | 担当BP のタスク（B-）。付録に引継ぎのめやす |

予算移管はプロジェクトではなく、GDS の各チームが普段の業務として行う活動である。専用の体制は作らず、全体の取りまとめは S&G が、案件ごとの実務は担当BP が行う（[憲章](../rules/02-charter.docx) 第6条）。日付は目安で、守るのは12月末の移管の稟議の承認である。

### 1.2 登場人物

| 登場人物 | 立場 | 関わり方 |
|---|---|---|
| S&G（FinanceBP） | 実務（取りまとめ） | 追補の公開と更新、問い合わせへの対応、全体の把握、移管対象の報告、移管の稟議、固定資産の扱いの確認と償却費の計上先の変更 |
| 担当BP | 実務（複数） | 案件ごとの移管対象の特定と合意、予算シートの更新、業務の引き継ぎ、固定資産の案件の特定。普段からファンクションの窓口を務める GDS のメンバー |
| 移管元の責任者 | 合意（移管元の部門長） | 移管対象の予算に合意し、移管の稟議の前提となる部門長同士の合意を行う |
| カウンターパート | 情報の提供・協議 | ヒアリングシートに答え、引き継ぎの時期を担当BP と協議する |
| GDS部門長 | 承認者（機能の責任者） | 移管対象の報告を受け、移管の稟議の前提となる部門長同士の合意を行う。確認依頼・保留課題を決める |
| 稟議の決裁者 | 決裁 | 移管の稟議を決裁する（決裁のルートは稟議システムによる） |
| 財務経理 | 相談 | 取得予定・将来取得の資産の扱いを確認する |
| ベンダーマネジメント担当・事務担当 | 移管の後の受け手 | 業務の引き継ぎで相談を受け、移管の後に契約の管理と、予算管理・発注・支払の事務手続きを担う |
| 新しいITガバナンスモデル（Tier）の運営主体 | 引き渡し先 | 移管の稟議が承認された案件の一覧を受け取る |

### 1.3 12月末の完了の定義

2026年12月末の時点で目指すのは、**移管の稟議が承認されていること**である（[憲章](../rules/02-charter.docx) 第3条第2項）。役割ごとの完了の定義は次のとおり。

| 役割 | 完了の定義 | 対応するタスク |
|---|---|---|
| 担当BP（経費予算） | ① 移管対象の予算が、移管元と合意されている　② 移管対象の予算が、予算シートに漏れなく記載されている　③ 移管対象の予算に紐づく業務の引き継ぎを開始している | B-01〜B-04（ステータス「引継ぎ開始」） |
| 担当BP（固定資産） | ① 取得予定・将来取得の案件が特定されている　② 既存資産は移さないことを移管元と確認している | B-05 |
| S&G（FinanceBP） | ① 移管の稟議が承認されている　② 結果が担当BP に連携されている　③ 取得予定の資産の償却費を GDS に計上する段取りができている | S-03、S-07〜S-09 |

業務の引き継ぎの完了、契約の名義変更、請求書の宛名の変更は、12月末の完了の定義に含めない。適切な時期に行えばよい（憲章 第9条第5項）。

## 3. RACI

R＝実行、A＝最終責任、C＝相談、I＝連絡。A は1行に1つとする。実務（R）は S&G と担当BP だけが持つ。

| No. | タスクID | タスク | S&G | 担当BP | 移管元の責任者 | カウンターパート | GDS部門長 | 稟議の決裁者 | 財務経理 | VM担当・事務担当 | Tier の運営主体 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| ① | S-01 | 追補を公開し、案内する | A/R | I | | | I | | | I | |
| ② | S-02 | 予算シートを提示し、担当BP を割り当てる | A/R | I | | | C | | | | |
| ③ | B-01 | 移管対象の予算を特定し、合意する | I | A/R | C | C | | | | | |
| ④ | B-02 | 予算シートに転記する | I | A/R | | C | | | | | |
| ⑤ | B-03 | ステータスを随時更新する | I | A/R | | | | | | | |
| ⑥ | B-04 | 契約・発注などの業務を引き継ぐ | I | A/R | | C | | | | C | |
| ⑦ | B-05 | 取得予定・将来取得の案件を特定し、伝える | I | A/R | C | C | | | | | |
| ⑧ | B-06 | 完了目処を報告する | I | A/R | | | | | | | |
| ⑨ | S-03 | 取得予定・将来取得の扱いを財務経理と確認する | A/R | I | | | | | C | | |
| ⑩ | S-04 | 全体の状況を把握する | A/R | C | | | | | | | |
| ⑪ | S-05 | 問い合わせに答え、QA表と追補を更新する | A/R | C | | | I | | | | |

- 移管の稟議の「移管元の責任者」「GDS部門長」の C は、部門長同士の合意（事前承認）を指す。
- VM担当＝ベンダーマネジメント担当。移管の後の間接業務の分担は、[業務フロー定義](./06-process-definition.pptx) の「移管後の役割分担」による。
- 契約の相手先・委託先は、予算移管のタスクには関わらない。契約の名義変更・請求書の宛名の変更は、適切な時期に行う。
