## 1. 業務用語

業務の流れの順に並べる。

| 用語 | 読み | 定義 | 定義の出典 | 備考 |
|---|---|---|---|---|
| 移管 | いかん | 移管対象部門のシステムに関する予算・契約と、契約に基づく間接業務を、IT部門へ移すこと | [憲章](../rules/02-charter.docx) 第3条、第4条 | 直接業務は移らない |
| 間接業務 | かんせつぎょうむ | 契約に基づいて生じる業務。予算の管理、契約の管理、発注・検収・支払い、委託先の管理、契約に関する監査・規制対応 | [憲章](../rules/02-charter.docx) 第4条第3項 | 移管の後はIT部門が担う |
| 直接業務 | ちょくせつぎょうむ | 契約の前提となる、移管対象部門の本来の業務。業務要件の決定、システムを使った業務の遂行、受け入れの確認、部門で行う運用、利用者への教育 | [憲章](../rules/02-charter.docx) 第4条第3項 | 組織のミッション・業務分掌・職務権限に基づき、移管の後も移管対象部門が担う |
| IT関連業務（中間層） | アイティーかんれんぎょうむ（ちゅうかんそう） | 直接業務と間接業務の間にある、業務アプリケーションに関する業務。投資では予算承認までの企画・見積の取得・申請書の作成、経費では運用のモニタリング・改善活動・契約の見直しに向けた活動など | [移管後の役割と業務プロセス](../appendix/01-post-transfer-operating-model.md) §3 | 案件ごとに、標準 RACI をカスタマイズした合意文書で扱いを決める。A はビジネスオーナーに残る |
| 移管対象部門 | いかんたいしょうぶもん | 移管の対象になる部門。営業部門以外の部門で、本社機能のうち人事・総務・財務を含む | [憲章](../rules/02-charter.docx) 第4条 | 移管対象部門には案内済み |
| 予算移管シート | よさんいかんシート | 予算一覧、紐付け、システム、業務、契約などのシートからなる、移管の台帳 | [憲章](../rules/02-charter.docx) 第6条 | ファイル名は budget_transfer_sheet.xlsx |
| 予算一覧 | よさんいちらん | 移管対象部門の予算シートに、移管判定と移管ステータスの列を足した案件の一覧。予算移管シートの1シート | [憲章](../rules/02-charter.docx) 第6条 | 案件一覧とも呼ぶ |
| 案件 | あんけん | 予算一覧の1行。移管対象部門の予算シートの1行に当たる | [憲章](../rules/02-charter.docx) 第8条 | |
| 予算区分 | よさんくぶん | 案件が投資予算か経費予算かの区分 | [憲章](../rules/02-charter.docx) 第8条 | |
| 投資予算 | とうしよさん | 新規導入・改修のための予算（設備投資・プロジェクト） | [憲章](../rules/02-charter.docx) 第8条 | 継続案件は移管対象部門に残り、新規案件は移管する |
| 継続案件 | けいぞくあんけん | 投資予算のうち、2026年度から続く案件。契約が済んでいるかを問わない | [憲章](../rules/02-charter.docx) 第8条第3項 | 対象外。予算は移管対象部門に残り、1回限りの支出の発注・検収を部門が行う。次の継続は IT部門 |
| 新規案件 | しんきあんけん | 投資予算のうち、2027年度に始まる案件 | [憲章](../rules/02-charter.docx) 第8条第3項 | 予算を移管し、IT部門が発注・検収を行う |
| 投資の区分 | とうしのくぶん | 投資予算の案件が、新規案件か継続案件かの区分 | [憲章](../rules/02-charter.docx) 第8条第3項 | 予算一覧の AZ 列 |
| 経費予算 | けいひよさん | 保守・ライセンス・運用のための予算 | [憲章](../rules/02-charter.docx) 第8条 | 契約と、契約に基づく間接業務を伴う |
| 費用の性質 | ひようのせいしつ | 経費予算の案件が、変動費・固定費・現場固有の増分のどれに当たるかの区分 | [Runbook 事務局編](../process/08-runbook-01-transfer-lead.md) §3.2 | 移管判定には使わない |
| システム関連 | システムかんれん | 案件がシステムの利用・保守・開発・運用に関わるかどうかの区分 | [憲章](../rules/02-charter.docx) 第8条 | |
| 棚卸し | たなおろし | システムに関わる移管対象部門の業務を、直接業務と間接業務に分けて予算移管シートの業務シートに書き出し、移管対象部門の確認を得ること | [Runbook 窓口担当編](../process/08-runbook-04-case-owner.md) §3.3 | 情報の聞き取りと記入は活動の開始の前（10月）、部門の確認は活動の開始の後。移管元の責任者の承認は要さない |
| 移管判定 | いかんはんてい | 予算移管シートの数式が出す、案件・契約・業務ごとの移管の扱い（移管・対象外・判定保留・—） | [憲章](../rules/02-charter.docx) 第8条 | |
| 判定保留 | はんていほりゅう | 判定に必要な入力が足りず、移管判定を出せない状態 | [憲章](../rules/02-charter.docx) 第8条 | |
| 一括移管 | いっかついかん | 移管する予算・契約・間接業務を、一括移管の実施日（2027-01-01）にまとめて移すこと。全ての案件の予算を一括して移す | [憲章](../rules/02-charter.docx) 第9条 | |
| 経過措置 | けいかそち | 今の担当が承認済みの文書や記録（SOP・規程・職務分掌など）で定められていて、担当の変更に正式な手続き（例：GxP の変更管理）が要る業務を、手続きが完了するまで今の担当のまま行うこと。IT関連業務の扱いが合意できない場合に、Before のまま行うことも含む | [憲章](../rules/02-charter.docx) 第9条第3項 | 予算は一括して移す。完了予定は合意文書と業務シート S列に書く |
| 合意文書 | ごういぶんしょ | 案件ごとに、標準 RACI（Before / After）をカスタマイズし、経過措置と引継ぎの方法を加えて、移管元の責任者が承認したもの | [Runbook 窓口担当編](../process/08-runbook-04-case-owner.md) §3.4 | カスタマイズできるのは IT関連業務の行の R の分担と、SO が R を持ち始める時期だけ |
| 12月末のゴール | じゅうにがつまつのゴール | 2026年12月末の時点で、移管の稟議が承認されていること。前提は、稟議に必要な情報の整理、完了していないことの明確化、1月から間接業務を始められる状態の3つ | [憲章](../rules/02-charter.docx) 第3条第2項 | SOPの改訂の完了、契約の署名者の変更、請求書の宛名の変更は含まない |
| 困難度 | こんなんど | 間接業務の引継ぎの難しさ。現場の関わり方と、要因（GxP対象・個人情報・SOP無）から決まる | [Runbook 窓口担当編](../process/08-runbook-04-case-owner.md) §3.4 | 移管するかどうかは変えない |
| 移管の稟議 | いかんのりんぎ | 移管する予算を、移管元の部門長とIT部門長の合意で IT部門へ移す稟議。事務局が部門ごとに起票し、2026-12-31までに完了させる | [憲章](../rules/02-charter.docx) 第9条第2項 | 経過措置がある案件の予算も含める |
| 引継ぎ要領 | ひきつぎようりょう | 窓口担当が間接業務を引き継ぐときに使う受け渡しの決まり。受け手、受け取るもの、請求書の宛名の変更に渡す情報を定める | [Runbook 窓口担当編](../process/08-runbook-04-case-owner.md) 付録 | 事務局が整える（承認は要さない）。移管の後の契約の精査・支払いの手順は受け手が定める |
| 移管ステータス | いかんステータス | 案件ごとの移管の進み具合。棚卸し中・棚卸し済み・合意済み・準備完了・対象外の5つ | [憲章](../rules/02-charter.docx) 第10条 | |
| IT予算移管ガイドライン | アイティーよさんいかんガイドライン | IT部門の各チームが予算移管を進めるときの拠り所。方針（守ること）と、目安・雛形（ビジネス部門と合意して決めること）を示す。IT部門向け予算ガイドラインの下位にあたる | [IT予算移管ガイドライン](../kickoff/IT予算移管_ガイドライン_2026-11.pptx) | 予算移管はプロジェクトではなく、専用の体制は作らない |
| 方針 | ほうしん | 全社で決まっていて守ること。一括移管（例外は経過措置だけ）、移すのは予算・契約・間接業務、A はプロセスオーナーに残る、12月末までの移管の稟議の承認、GxP 対象の業務は品質保証部門の定めが正 | [IT予算移管ガイドライン](../kickoff/IT予算移管_ガイドライン_2026-11.pptx) | |
| 目安・雛形 | めやす・ひながた | 方針以外の進め方。日付、IT関連業務の R の分担と時期、引継ぎの方法、経過措置、体制の役割分担、合意文書の形。ビジネス部門と合意して決める | [IT予算移管ガイドライン](../kickoff/IT予算移管_ガイドライン_2026-11.pptx) | |
| 型A・型B（固定資産） | かたエー・かたビー | 固定資産の持ち方の型。型A（標準）は予算を持つ IT部門が資産と償却費も管理する。型B（個別に選択）は受益部門が資産と償却費を持つ | [IT予算移管ガイドライン](../kickoff/IT予算移管_ガイドライン_2026-11.pptx) 第3章 | 型B を選ぶときは経理部門の確認を得る。減価償却費は予算移管の対象ではなく、資産を管理する部門に計上する |
| Showback／Chargeback | ショーバック／チャージバック | Showback＝コストセンターを分けて費用を見せること。Chargeback＝受益部門に費用を計上（配賦）すること | [IT予算移管ガイドライン](../kickoff/IT予算移管_ガイドライン_2026-11.pptx) 第3章 | 本社機能は Showback で足りる。研究開発・製造の費用と償却費は、会計上の区分を保つため受益部門に配賦する |
| ビジネスオーナーシップ | ビジネスオーナーシップ | 案件の要否・目的・効果と業務要件を決め、直接業務を遂行する責任 | [憲章](../rules/02-charter.docx) 第7条 | 移管の後も移管対象部門に残る |

## 4. 使い分け

| 区別すべき語 | 使い分け |
|---|---|
| 「移管元の責任者」と「移管対象部門の担当者」 | 移管元の責任者＝承認を行う。担当者＝情報と資料を提供する。どちらも実務は行わない |
| 「実務」と「承認」 | 実務＝事務局と窓口担当が行う作業。承認＝移管元の責任者・IT部門長が、事務局・窓口担当の作った案や結果を認めること |
| 「事務局」と「窓口担当」 | 事務局＝全体と部門の単位の作業（ガイドラインの公開と説明、割当て、引継ぎ要領、稟議、確認、まとめ）と IT部門長への依頼。窓口担当＝案件の単位の作業と、移管元の責任者への承認の依頼 |
| 「予算の承認」と「予算の移管」 | 予算の承認＝取締役会が会社全体の予算を承認すること（移管する予算も部門の予算として計上する）。予算の移管＝承認の後、部門長同士の合意（移管の稟議）で IT部門へ移すこと |
| 「移管判定」と「経過措置」 | 移管判定＝移すかどうか。基準（憲章 第8条）で自動的に決まる。経過措置＝移したうえで、担当の変更の手続きが終わるまで今の担当のまま行うこと。予算の移管の時期は変わらない |
| 「移管判定」と「移管ステータス」 | 移管判定＝移すかどうか（数式で自動）。移管ステータス＝移管がどこまで進んだか（予算移管事務局が更新） |
| 「直接業務」と「間接業務」 | 直接業務＝契約の前提となる部門の本来の業務（移管しない）。間接業務＝契約に基づいて生じる業務（移管する）。例えば営業部門の予算を移管しても、IT部門は営業活動をしない |
| 「移管する」と「決裁権を持つ」 | 移管する＝予算・契約と、契約に基づく間接業務の所在をIT部門に移す。決裁権を持つ＝案件の実行を承認する。移管したものの決裁権は新しいITガバナンス（Tier）が決める |
| 「予算区分」と「費用の性質」 | 予算区分＝投資予算か経費予算か（移管判定に使う）。費用の性質＝変動費・固定費・現場固有の増分（移管した費用の見せ方・配賦に使う） |

## 5. 旧制度の用語との対応

2026-09-21版の手順書（外部性で移管を判定する方式。廃止）で使っていた語との対応。

| 旧用語 | 新用語 | 補足 |
|---|---|---|
| 要員ごと移管 | （廃止） | 部門が自ら行う運用・開発は直接業務として部門に残るため、要員を移す方法は置かない |
| 留保 | （廃止） | 外部性の低いシステムを移管しない扱い。移管できるものはすべて移管することにしたため廃止 |
| 外部性・安定性 | （移管判定には使わない） | 外部性・共通性は、新しいITガバナンス（Tier）で決裁権を決めるときに使う |
| 初年度／2年目以降 | 一括移管（個別移管は廃止） | |
| 申告（予算・契約・業務） | 移管対象部門のコメント | 移すかどうかの希望は聞かず、一括移管への懸念・条件を聞く |
| 予算シート（AL〜AN 列） | 予算一覧（AL〜AO 列） | |
