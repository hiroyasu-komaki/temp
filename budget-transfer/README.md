# IT予算移管

2027年度の予算編成から、移管元のファンクション（営業部門以外。本社機能のうち人事・総務・財務を含む）の**システムに関する経費予算**と、それに伴う**間接業務（予算管理・契約管理・発注・支払）**を、2027-01-01 に GDS へ一括して移す。設備投資の予算と既存の固定資産は移さず、今後取得する固定資産から GDS が管理する。

予算移管はプロジェクトではなく、**GDS の各チームが普段の業務として行う活動**である。全体の取りまとめは S&G（FinanceBP）が、案件ごとの実務は担当BP が行う。拠り所は [追補「IT予算移管の要点」](./kickoff/IT予算移管の要点_予算ガイドライン追補.pptx) で、GDS の全員が閲覧できる Teams チャネルで案内している。

**今期の目標：2026年12月末までに、移管の稟議が承認されていること。**

## 追補の要点

**11月〜12月の進め方（目安）**

| 時期 | 担当BP | S&G（FinanceBP） |
|---|---|---|
| 11月 | ヒアリングシートで移管対象の予算を特定し移管元と合意、予算シートに転記（対象外は除外、追加分は追記）、ステータスを随時更新、契約・発注などの業務の引き継ぎ（開始時期はカウンターパートと協議）。取得予定・将来取得の案件を特定し FinanceBP に伝える | 取得予定・将来取得の扱いを財務経理と確認。予算シートで全体を把握 |
| 11月末 | 完了目処を報告（間に合わない案件は「要協議」にして協議） | — |
| 12月第1週 | 作業の完了 | 11月末の目処を受けて移管対象を報告 |
| 12月 | — | 稟議の準備（申請単位・事前承認・関係者への連絡）・申請、結果を担当BP に連携（承認の目安は第3週の前半） |
| 2027年1月〜 | — | 取得予定の資産の振替の時点で、償却費の計上先を GDS にする |

- 年内に発注が必要な案件は、予算移管を待たずに可能な範囲で手続きを始める。契約の名義変更は予算移管と同時である必要はない。

**12月末の完了の定義**

- 担当BP（経費予算）：① 移管対象の予算が移管元と合意されている　② 予算シートに漏れなく記載されている　③ 紐づく業務の引き継ぎを開始している
- 担当BP（固定資産）：① 取得予定・将来取得の案件が特定されている　② 既存資産は移さないことを移管元と確認している
- S&G：① 移管の稟議が承認されている　② 結果が担当BP に連携されている　③ 取得予定の資産の償却費を GDS に計上する段取りができている

**移管後の役割分担**

- 各ファンクションは「何を・なぜ実現するか」（ビジネス戦略・ビジネス要件・ビジネス効果。R・A）を決め、GDS は「どう実現するか」（IT戦略・システム要件・ソリューション・ベンダー。R・A、各ファンクションは C）をリードして決める。全社共通と個別最適のバランスは GDS がとる。
- 部門に閉じた案件は、システム要件までを各ファンクションがリードしてよい。ソリューション選定とベンダー選定は、どの案件でも GDS がリードする。
- 役割分担が試される4つの場面（案件の持ち込み、ソリューション選定、意見が割れたとき、受け入れ）の問いと仮説を、役割分担プレイブックとして示す。

**固定資産**

| 区分 | 固定資産管理 | 減価償却費 |
|---|---|---|
| ① 既存資産（償却中・簿価ゼロを含む）と長期前払費用 | 移管元（台帳は変えない） | 移管元（償却が終わるまで） |
| ② 取得予定（構築中で、移管の後に本勘定へ振り替える） | 仮勘定は移管元、振替の時点から GDS | 振替の時点から GDS |
| ③ 将来取得（移管の後に着手する IT投資） | 仮勘定の時点から GDS | GDS |
| 既存資産の改修（推奨） | 改修分は③と同じく GDS、本体は移管元 | 改修分は GDS |

- 設備投資の予算は予算移管の対象にしない。新規案件を GDS が管理することで、年を追って管理の主体が GDS に移っていく。

| 財務経理 | 財務経理 | 取得予定・将来取得の資産の扱いの確認 |

## 管理台帳（ledger/）

案件ごとの移管判定とステータスは、予算移管シートで共有する。報告書は作らず、担当BP がステータスを随時更新し、S&G が随時確認する。担当BP が報告するのは、11月末の完了目処だけである。

| シート | 役割 | 更新する者 |
|---|---|---|
| 予算一覧 | 1行＝1案件。移管判定（自動。経費予算＝移管、投資予算（設備投資）・システムと無関係＝対象外）、ステータス（未着手・確認中・合意済み・引継ぎ開始・要協議・対象外）、完了目処 | S&G（登録・担当BP の割当て）、担当BP（判定の入力・ステータス・完了目処） |
| 移管元 | 移管元ごとの責任者・カウンターパート、集計、既存資産を移さないことの確認日、稟議の申請単位・日付 | S&G、担当BP（確認日） |
| 固定資産 | 取得予定・将来取得・既存資産の改修の案件と、FinanceBP への連絡・財務経理との確認 | 担当BP、S&G |
| モニタリング | ステータス別・判定別・完了目処・移管元別・固定資産の集計（自動） | — |

列や数式を変えるときは、先に [予算移管シート 仕様](./ledger/budget_transfer_sheet_spec.md) を直す。

## 今の状態（2026-11-07）

- 2026-11-02 に追補「IT予算移管の要点」初版を公開し、活動を開始した（決定記録「決定事項」No.70）。固定資産は 2026-11-05 の関係者・財務経理のフィードバックを反映済み（No.72・No.73）。
- 2026-11-07 に、追補に合わせて全文書を改訂した（各文書 2.0）。主な変更：
  - 呼称を社内の呼び方（GDS・各ファンクション・S&G（FinanceBP）・担当BP・GDS部門長）に改めた。
  - 対象を経費予算と間接業務とし、設備投資の予算を対象外にした。
  - 合意文書・経過措置・IT関連業務（中間層）・準備完了・引継ぎ要領の確定・型A/型B・Showback／Chargeback を廃止し、追補の進め方・完了の定義・役割分担・固定資産の扱いに置き換えた（旧用語は用語集 §5）。
  - 予算移管シートを5シートに作り直した（進捗・タスク一覧・紐付け・システム・業務・契約・判定表は廃止）。
- 文書一式は承認前の案で、GDS部門長の承認を待っている。
- 未確定事項は、決定記録「保留課題」に5件（投資予算と経費予算の境目、変更依頼への回答期限、削減分を返す比率、KPI の目標値、事務担当の体制）。
- 作る人が判断した事項は、決定記録「確認依頼」No.41〜No.49（ステータスの定義、予算移管シートの構成、カレンダーの目安日など）。
