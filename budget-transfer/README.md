# IT予算移管

2027年度の予算編成から、移管対象部門（営業部門以外の部門）のシステムに関する予算・契約と、契約に基づく間接業務（予算・契約の管理、発注・検収・支払い、委託先の管理など）を IT部門へ移す。

予算移管はプロジェクトではなく、**IT部門の各チームが普段の業務として行う活動**である。キックオフのような場や専用の体制は設けない。各チームは [IT予算移管ガイドライン](./kickoff/IT予算移管_ガイドライン_2026-11.pptx) を拠り所に、普段のカウンターパートであるビジネス部門と合意しながら進める。

```

└─ IT部門向け予算ガイドライン（IT部門）

```

- 上位の定めが優先する。ガイドラインと憲章・手順書に食い違いがあれば、ガイドラインに従う。
- GxP 対象の業務は、品質保証部門が定める SOP・手順が正となる。本フォルダの役割分担（RACI）は雛形として使う。

## ガイドラインの要点

**方針（全社で決まっていること。守る）**

- すべての予算を 2027-01-01 に一括で移す。例外は経過措置だけ（今の担当が承認済みの文書で定められ、担当の変更に正式な手続きが要る業務は、手続きが終わるまで今の担当が続ける。予算は移る）。
- 移すのは予算・契約・間接業務。直接業務は部門に残る。
- 業務の最終責任（A）はプロセスオーナーに残る。
- 2026年12月末までに、移管の稟議が承認されること。
- GxP 対象の業務は、品質保証部門の定めが正となる。

**目安と雛形（各チームがビジネス部門と合意して決める）**

- 11月〜12月の進め方と日付（合意の目安 12/11、準備完了の確認の目安 12/18）。
- IT関連業務（中間層）の R の分担と、SO が R を持ち始める時期。部門と SO の両方が R を持って協力する（部門が C に下がって IT部門に任せる形にはしない）。
- 引継ぎの方法と、経過措置の業務・完了予定。
- プロジェクト体制・運用体制の役割と成果物の分担（RACI の適用例）。
- 合意文書の形と粒度。

**固定資産**

- 型A（標準）：予算を持つ IT部門が資産と償却費も管理する。型B（個別に選択）：受益部門が資産と償却費を持つ（選ぶときは経理部門の確認を得る）。
- 減価償却費は予算移管の対象ではなく、資産を管理する部門に計上する。
- 型A では、Showback（費用を見せる）と Chargeback（受益部門への計上）を分ける。本社機能は Showback で足りる。研究開発・製造に関わる費用と償却費は、会計上の区分を保つため受益部門に配賦する（方法は経理部門と決める）。

**役割**

- **窓口担当**：普段からその案件でビジネス部門のカウンターパートを務めている各チームのメンバー。案件ごとの実務と、ビジネス部門との合意を担う。
- **予算移管事務局（事務局）**：全体の取りまとめ、ガイドラインの公開と説明、移管ステータスの確認、移管の稟議の起票、IT部門長への相談。

## 管理台帳（ledger/）

案件ごとの移管判定と移管ステータスは、予算移管シートで共有する。報告書は作らず、シートを更新すれば事務局が毎日確認する。

| ファイル | 役割 | 更新する者 |
|---|---|---|
| [予算移管シート](./ledger/budget_transfer_sheet.xlsx) | 案件（予算一覧の1行）ごとの移管判定と移管ステータス、役割別のタスクの進捗（「進捗」シート）。「モニタリング」シートで自動集計する | 事務局（登録・窓口担当の割当て・全体の承認の記録）、窓口担当（担当する案件の記入・移管ステータス・案件の承認の記録）、それぞれ自分のタスクの進捗 |
| [予算移管シート 仕様](./ledger/budget_transfer_sheet_spec.md) | シート構成、データモデル、自動判定のしくみ。列や数式を変えるときは、先にこの仕様を直す | 予算移管事務局 |

## 今の状態（2026-10-17）

- 文書一式は承認前の案で、IT部門長の承認を待っている。
- 2026-10-17 に、資料一式をガイドライン中心に組み直した（決定記録「決定事項」No.55〜No.63）。
  - 予算移管をプロジェクトではなく各チームの活動と位置づけ、キックオフ資料を IT予算移管ガイドラインに改めた。進行役を事務局、案件担当を窓口担当に改め、日付は目安とした。
  - IT関連業務は部門と SO の両方が R を持って協力する形にし、経費プロセスに決める行（SLA の要求、利用ルール、契約を続けるかどうか）を加えた。RACI の適用例（プロジェクト体制・運用体制）を雛形として示した。
  - GxP 対象の業務は品質保証部門の定めが正とした。
  - 固定資産は型A（IT部門が持つ）を標準、型B（受益部門）を個別の選択とし、Showback と Chargeback を分けた。
- 未確定事項は、決定記録「保留課題」に7件（投資予算と経費予算の境目、変更依頼への回答期限、削減分を返す比率、KPIの目標値、事務担当の体制、研究開発・製造の費用の配賦の方法、移管前の資産を IT部門に移すか）。
- 作る人が判断した事項は、決定記録「確認依頼」に40件。IT部門長の確認を待っている。
