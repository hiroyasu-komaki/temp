# アーカイブ

本フォルダは、フレームワークから切り離した旧素材の保管場所である。削除はしていない。

- `proposal/施策企画書.md` … 旧・投資提案書（第I部 投資提案／第II部 構造分析／第III部 キャパシティ）。
  第II部（問題の本質・空白地帯・RACI・シーケンス）は `html/02_Organizational_Void.html` に再構成して移設済み。
  第I部・第III部（効果試算、NPV／IRR／PI、コスト構造、承認依頼、準備費用、キャパシティ試算）は、
  本フレームワークが投資承認を求める文書ではなくなったため全面的に切り離した。
- `image/` … 上記第I部・第III部のグラフ（削減額、NPV/IRR、コスト構造、随契内訳）。
- `input/vmo_impact_model.xlsx` … 上記の効果試算モデル。

投資判断を別途起案する必要が生じた場合は、本フォルダの素材を独立した文書として再構成すること。
フレームワーク本体（`index.html` および `html/`）には、金額・投資指標を持ち込まない。
