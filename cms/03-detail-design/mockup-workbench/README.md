# 審議ワークベンチの紙芝居（モックアップ）

- **最終更新**: 2026-09-23
- **対象**: 審議ワークベンチ（事務局・審査担当者・委員会・PPM、日本語のみ）の画面項目と動作イメージ
- **根拠**: [画面設計](../01-screen-design.md)、[状態遷移](../03-state-transitions.md)、[フロー設計](../../02-architecture/03-api-design.md)

## 開き方

`index.html` をブラウザ（Edge／Chrome／Safari）で直接開く。インターネット接続・インストール不要。

## 使い方

- 右側の「ロールを切り替える」で、事務局・審査担当者・委員長・委員・PPM の見え方を比べる。
- ホーム（W1）はロールごとに「自分の番」の案件だけが出る。行を押すと案件詳細（W3）を開く。
- 案件詳細の操作ボタン（D1〜D14）は、今の状態とロールの両方が合うときだけ出る。押すとダイアログが開き、登録すると状態が進む。
- 起案者の操作（確認完了、疑義・意見、議論要請、取り下げ）は申請用アプリ側で行うため、右側の「申請用アプリ側の操作を再現」で代わりに実行できる。

## 通しで試す例（LIMS の更新 IC-2026-0012）

1. 審査担当者：確認表を選択する → 自分の担当行を「確認済み」
2. 右側：起案者が「確認完了」を登録する → 自動で「審議待ち」へ
3. 事務局：委員会へ回答を依頼する → 委員長：審議結果を登録する
4. 事務局：回答書（案）を登録する → 委員長：内容を確認済みにする → 事務局：回答書を確定する
5. 委員：議論を要請する（または右側で受付期限を過ぎたことにする）
6. 事務局：招集情報を登録 → 結果を確定登録する → PPM のホームに出る

## 注意

- 実際の画面は Power Apps の標準部品で作るため、見た目は異なる。
- 案件はすべて架空のサンプル。操作はこのページの中だけで反映され、再読込で元に戻る。
- ファイルの選択・「開く」・PDF 出力は見た目だけ（実際のファイルは扱わない）。
- 画面・ルールの正は画面設計と状態遷移。紙芝居と食い違う場合はそちらを正とし、紙芝居を直す。
