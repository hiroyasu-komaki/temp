# 申請画面の紙芝居（モックアップ）

- **最終更新**: 2026-09-23
- **対象**: 申請画面（Power Apps）の画面項目と動作イメージ。関係者への事前共有用
- **根拠**: [業務ドメイン構造](../../01-requirements/01-domain-structure.md)、[機能スコープ](../../01-requirements/03-functional-scope.md)、ADR-0004

## 開き方

`index.html` をブラウザで開く（インターネット接続・インストール不要）。右側の「画面へ移動」で任意の画面へ飛べる。

## 画面

1. マイ申請（下書きの再開・新規申請）
2. 基本情報（申請メタデータ）
3. 資料添付・自動生成（再生成は確認のうえ全項目上書き）
4. 案件概要書の確認・修正（AI生成／修正／入力／記載なしの表示、出所、資料間の不一致、必須チェック、PDF出力）
5. 通知先
6. 確認・申請（未入力の必須一覧、内容確認チェック、PDF出力）
7. 申請完了

## 注意

- 実際の画面は Power Apps の標準部品で作るため、見た目は異なる。
- 画面右上で表示言語（日本語／English）を切り替えられる。入力値（サンプル）は翻訳しない。PDF の見出しも表示言語に合わせる。
- PDF出力は、ブラウザの印刷画面で「PDFに保存」を選ぶ（ポップアップの許可が必要な場合がある）。実システムでは Power Automate で PDF を作る想定。
- 値は架空の案件（LIMS の更新）のサンプル。自動生成は擬似的な動作で、AI は呼び出していない。
- 項目・ルールの正は業務ドメイン構造。紙芝居と食い違う場合は業務ドメイン構造を正とし、紙芝居を直す。
