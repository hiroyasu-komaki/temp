## 2. 組織・ロール

詳細な権限は [ロールと権限](../01-requirements/05-roles-and-permissions.md)。

| ロール | 誰か | CMS での役割 |
|---|---|---|
| 起案者 | 事業部門の起案担当 | 申請、論点整理書への疑義・意見、確認完了、議論要請 |
| 事務局 | 投資委員会の事務局。案件ごとに1名以上を担当に割り当てる | 論点整理書・審議回答書の登録と修正、回付、招集、議事録登録、承認結果の確定登録 |
| 審査担当者 | IT部門の各ケイパビリティ担当（一次資料では「ケイパビリティ担当者」） | 確認表の選択、論点へのリスク記載 |
| 投資委員会メンバー | 委員 | 審議結果の登録、回答書の内容確認・修正依頼、議論要請 |
| PPM（ポートフォリオ管理） | 機能としてのPPM担当 | 承認案件・承認条件の受領（①）。モニタリング以降は③ |
| CMS管理者 | IT部門 | 設定・マスタの保守 |

## 4. 本ドキュメント内での用語の使い分け

| 区別すべき語 | 使い分け |
|---|---|
| 「手元資料」と「案件概要書」 | 手元資料＝添付ファイル（原本）。案件概要書＝そこから生成・確認した構造化データ |
| 「案件概要書の自動生成」と「論点整理書ドラフター」 | どちらも AI。前者は起案者が申請画面で使う（CMS 内）。後者は事務局が Step1 で使う（①では CMS の外） |
| 「審議結果」と「審議回答書」 | 審議結果＝委員会が登録する判定。審議回答書＝事務局が作り委員会が確定する文書 |
| 「確認完了」（起案者）と「内容確認完了」（委員会） | 前者は Step1 の論点整理書、後者は Step2 の審議回答書 |
| 「疑義」と「議論要請」 | 疑義＝Step1 の書面の意見。議論要請＝Step2 後に会議を求めること |
