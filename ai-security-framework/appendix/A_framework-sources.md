# 付録A　参照した枠組みと版

> **種別**：理論的背景（出典・版の一覧）
> **参照元**：全章

## 目的

本資料が依拠する外部の枠組みについて、参照した版と入手先を固定して記録する。枠組みが改訂されたときに、どの章を見直すべきかを判断する基準にする。
