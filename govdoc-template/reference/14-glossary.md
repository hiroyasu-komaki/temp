## 4. 使い分け

| 区別すべき語 | 使い分け |
|---|---|
| {{例: 「予算承認」と「実行承認」}} | {{例: 予算承認＝予算計上の可否。実行承認＝実行計画（手段と支出）の承認}} |
| {{例: 「審議」と「報告」}} | {{例: 審議＝会議体が決定する。報告＝会議体は決定せず、事実を受け取る}} |
| {{例（B型）: 「支援」と「代行」}} | {{例: 支援＝判断の材料を出し、決めるのは依頼者。代行＝依頼者に代わって実行するが、決めるのは依頼者のまま}} |
| {{例（D型）: 「指摘」と「不適合」}} | {{例: 指摘＝改善を求める事項（期限内に是正すればよい）。不適合＝基準を満たしていない状態（是正し、報告する）}} |
