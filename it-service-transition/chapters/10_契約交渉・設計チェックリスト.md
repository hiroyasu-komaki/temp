# 10. 契約交渉・設計チェックリスト

> **この章の位置づけ**：第3章〜第7章で整理した論点を、契約交渉・設計の実務で使えるチェックリストに落とし込む章である。
> **対象読者**：交渉責任者／調達部門／ベンダーマネジメント担当者

## 要旨

これまでの章で整理した価格モデル・SLA/サービスクレジット・要員体制・ベンチマーキング/価格改定・グローバルデリバリーモデルの論点を、確認状況を管理できるチェックリスト形式でまとめる。

## 10.1 チェックリスト

| 確認 | 分類 | チェック項目 |
|---|---|---|
| □ | 価格モデル | 合意済みの価格体系が第3章のどの類型に近いかの確認 |
| □ | 価格モデル | アウトカムベースの要素をどの程度組み込むかの検討 |
| □ | SLA・サービスクレジット | 測定指標の選定(第4章の代表的KPIを参照) |
| □ | SLA・サービスクレジット | サービスクレジットの算定方法・上限・アーンバック条項の要否 |
| □ | SLA・サービスクレジット | レビュー頻度・報告フォーマットの合意 |
| □ | 要員体制 | 離職率・平均在籍期間の定例報告義務の組み込み |
| □ | 要員体制 | オンボーディング体制の説明資料の契約添付 |
| □ | 価格改定・ベンチマーキング | ベンチマーキング条項の要否・頻度の合意 |
| □ | 価格改定・ベンチマーキング | 正規化方法・費用負担・紛争解決手続きの明確化 |
| □ | その他 | グローバルデリバリー拠点構成とBCPの確認 |
| □ | その他 | L1.5の契約範囲への含め方の確認 |
| □ | その他 | 契約期間・更新・解約条件の確認 |

## この章の結論

- チェックリストは、価格モデル・SLA/サービスクレジット・要員体制・価格改定/ベンチマーキング・その他の5分類、計12項目に整理した。
- 各項目は第3章〜第7章のいずれかの論点に対応しており、詳細はそれぞれの章を参照する。
