# integration — データ連携（iPaaS・EAI・ファイル転送）

**一言でいうと**：別々のシステムの間でデータを受け渡し、変換し、処理を制御する仕組み。連携を専用の基盤（ハブ）に集め、その基盤をクラウドで提供するものを iPaaS と呼ぶ。

- **扱うこと**：データ連携の定義と方式、連携基盤の構造、製品と提供形態、連携基盤に本質的に伴う論点（ハブ、インスタンス、配置、データの保持、同期・非同期、規制対応）、隣接領域との境界
- **扱わないこと**：どのデータが正かの決定（マスタデータ管理）、データの蓄積と分析（分析基盤）、個別製品の設定手順
- 当社の現状は 06章にだけ書く
