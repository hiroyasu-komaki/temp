# analytics — 分析基盤（DWH・データレイク・BI）

**一言でいうと**：業務システムのデータを集めて蓄積し、分析できる形に整え、ダッシュボードなどで見せる仕組み。

- **扱うこと**：DWH・データレイク・レイクハウスの定義と構成、オープンテーブルフォーマット、データモデル（Inmon・Kimball・Data Vault）、メダリオン、主要な DWH・レイクハウス・BI 製品、論点、隣接領域との境界
- **扱わないこと**：システム間のデータ連携（→ integration）、マスタの正本（→ master-data）、機械学習・生成AI（→ ai）
- 当社固有の情報は 06章にだけ書く（未作成）
