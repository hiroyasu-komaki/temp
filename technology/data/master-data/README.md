# master-data — マスタデータ管理（MDM）

**一言でいうと**：品目・取引先・顧客など、多くのシステムが共通に使う基準のデータについて、どこが正本か・誰が変えてよいか・どう品質を保って配るかを決めて守る取り組み。

- **扱うこと**：MDM の定義、マスタデータと参照データ、System of Record、医薬品の IDMP、4つの実装スタイル、照合と統合、ガバナンス、主要製品と外部データサービス、論点、隣接領域との境界
- **扱わないこと**：マスタを配る仕組み（→ integration）、取引データの処理（→ erp など）、分析（→ analytics）
- 当社固有の情報は 06章にだけ書く（未作成）
