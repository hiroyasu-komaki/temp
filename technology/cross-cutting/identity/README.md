# identity — ID・アクセス管理（IAM）

**一言でいうと**：誰が・本人であることをどう確かめ・何にアクセスしてよいかを、入社から退職まで一貫して管理する、組織共通の基盤と運用。

- **扱うこと**：IAM の定義と成り立ち、構成要素（ディレクトリ、IdP・SSO、IGA、PAM）、ID のライフサイクル、NIST SP 800-63 の3つの指標、SCIM、主要製品、論点、隣接領域との境界
- **扱わないこと**：アプリの中の認証・認可の作り方と、顧客向けにアプリへ組み込む認証（→ web-security）、攻撃の検知と対応（→ security-operations）
- 当社固有の情報は 06章にだけ書く（未作成）
