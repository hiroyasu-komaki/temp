# function-allocation — 機能配置（システム間の境界）

**一言でいうと**：どのシステムが、どのデータと判断の正本を持ち、何を受け渡すか。technology/ の各トピックの間の「線」を1か所にまとめた資料。

- **扱うこと**：システム間の機能配置の原則、全体の俯瞰図、重要な関係性（人とマスタの配り方、品質・規制の判断と出荷の制御、基盤・運用・セキュリティの分担）、全トピックの境界の一覧、製品によって動く境界と重なる境界
- **扱わないこと**：ビジネスと IT の役割分担（何を・なぜ実現するかと、どう実現するか → governance/budget-transfer の kickoff 資料）、各システムの中身（→ 各トピックの01〜04章）、当社の現状の配置と課題（→ 各トピックの06章）
