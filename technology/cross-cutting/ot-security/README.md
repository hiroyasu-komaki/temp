# ot-security — OT（制御系）のセキュリティ

**一言でいうと**：工場の制御システム（PLC・SCADA・DCS・HMI など）と、それにつながる設備・計装を、サイバー攻撃から守る取り組み。IT と違い、**安全と止めないこと（可用性）を最優先にし、古くて更新しにくい機器を前提に**守る。

- **扱うこと**：OT セキュリティの用語、IEC 62443・NIST SP 800-82・経済産業省の工場セキュリティガイドライン、主な事例、パデューモデルと産業用 DMZ、ゾーンとコンジット、セキュリティレベル、主な対策（資産の把握・ネットワークの分離・リモートアクセス・パッチと補償的な対策）、CPS 保護の製品、論点、隣接領域との境界
- **扱わないこと**：製造のシステムの機能と、IT と OT の管掌の区分（→ [manufacturing](../../application/manufacturing/README.md)）、全社の検知と対応の運用（→ [security-operations](../security-operations/README.md)）、製造の記録の信頼性（→ [gxp-compliance](../../cross-cutting/gxp-compliance/README.md)）
- 当社固有の情報は 06章にだけ書く（未作成）

## 読み方

- 隣接領域との境界（どのシステムが何を持つか）は [function-allocation](../../cross-cutting/function-allocation/function-allocation.md) にまとめている。
- 01 → 02 → 03 → 04 → 05 の順に読む。IT と OT の性質の違い（優先順位・寿命）は manufacturing 05章の表を前提にする。
- 正本は `chapters/` の Markdown。
