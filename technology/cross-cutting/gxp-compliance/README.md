# gxp-compliance — GxP のコンピュータ化システム（CSV／データインテグリティ）

**一言でいうと**：医薬品の品質・安全性に関わる記録を扱うシステムが、**意図どおりに動くことを確かめ（バリデーション）、記録が正しく完全なまま保たれる（データインテグリティ）**ようにするための要件と仕組み。特定の業務領域ではなく、GxP の記録を扱うすべてのシステムに横断でかかる。

- **扱うこと**：GxP・CSV・CSA・データインテグリティの用語、21 CFR Part 11・EU GMP Annex 11・国内の ER/ES 指針と CSV ガイドライン、ALCOA+、システムが備える機能（監査証跡・電子署名・アクセス制御など）、バリデーションのライフサイクル、GAMP 5 のソフトウェアカテゴリ、SaaS での責任分担、検証の支援製品、論点、隣接領域との境界
- **扱わないこと**：社内の SOP・体制・承認の手順（→ governance 側、未作成）、QMS などの品質業務のシステムそのもの（→ [quality-regulatory](../../application/quality-regulatory/README.md)）、製造設備の適格性評価（→ [manufacturing](../../application/manufacturing/README.md)）
- 当社固有の情報は 06章にだけ書く（未作成）

## 読み方

- 隣接領域との境界（どのシステムが何を持つか）は [function-allocation](../../cross-cutting/function-allocation/function-allocation.md) にまとめている。
- 01 → 02 → 03 → 04 → 05 の順に読む。
- 正本は `chapters/` の Markdown。
