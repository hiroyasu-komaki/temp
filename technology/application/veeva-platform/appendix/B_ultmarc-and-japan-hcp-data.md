# 付録B　Ultmarc と日本の HCP/HCO データ

> **参照元**：[付録H](H_data-products.md)

[付録H](H_data-products.md)（データ領域の製品）の補足として、日本の医師・施設マスタを担う Ultmarc（日本アルトマーク）の沿革とデータの内容をまとめます。

> 件数・金額は記載の時点のものです。契約条件は Ultmarc・Veeva に確認してください。

---

## B-1 沿革

| 時期 | 出来事 |
|------|--------|
| 1962年3月 | 日本アルトマーク設立 |
| 2013年5月 | NTTドコモが発行済株式の約77.5%を約26億円で取得 |
| 2015年5月 | NTTドコモの完全子会社になる |
| 2019年4月 | エムスリーが NTTドコモから全株式を約66億円で取得し、完全子会社化。m3.com（医師会員27万人以上）のサービスと連携させ、製薬業界向けのマーケティング支援を強化する狙い |

現在はエムスリーグループの会社として、メディカルデータベース（MDB）を提供しています。

## B-2 MDB（メディカルデータベース）の概要

| 項目 | 内容 |
|------|------|
| 中身 | 全国の医療機関と、そこに勤務する医師・薬剤師などのマスターデータ |
| 利用者 | 医療・福祉・保健などの分野に限った会員制。会員は製薬企業をはじめとする医療関連企業・団体で、2014年8月時点で195社、2015年4月時点で207社、2019年時点で約250の企業・行政機関 |
| 運営モデル | 会員企業が持つ情報を日本アルトマークに提供し、データの正確さと網羅性を共同で維持する（個人情報保護法上の「共同利用」） |
| 提供方法 | 従来はデータファイルを VAN や CD-ROM で提供。2014年10月からはクラウド経由の「Cloud MDB」も提供 |
| Veeva 経由の利用 | Veeva 経由で使う場合も、Ultmarc の利用料が別に発生する |

## B-3 MDB に含まれる主な項目

会員企業が日本アルトマークと共同利用する個人データの項目として、次のものが公表されています。

- 個人：氏名、性別、生年月日、出身都道府県、卒業年、出身校、資格登録年
- 勤務：施設名、施設住所、施設電話番号、施設種別、診療科目、所属部科、役職・大学職位、開勤区分、開業年
- その他：学会、加入医師会・加入歯科医師会

施設・医師には DCF コード（施設コード・医師コード）が振られ、業界共通の識別子として使われます（→ 付録H「H-5 識別子」）。

## B-4 「OpenData」という名称について

Veeva OpenData の「Open」は、データを第三者のパートナーと使いやすくする方針を指します。Veeva は OpenData Partner Program を通じて、データ提供元・利用企業・パートナーの三者契約を不要にしています。「無料」という意味ではなく、有料のサブスクリプションです。
