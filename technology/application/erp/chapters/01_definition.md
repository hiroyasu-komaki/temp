# 01 ERPの定義と範囲

## 要旨

ERP（Enterprise Resource Planning）は、会計・販売・購買・在庫・生産など企業の基幹業務を、**1つのデータベースの上で統合して処理する**パッケージソフトウェアである。本質は機能の多さではなく、**同じデータを全業務で共有すること**にある。

## 定義

企業の経営資源（ヒト・モノ・カネ）にかかわる基幹業務を、共通のマスタと単一のデータベースで統合管理するシステム。業務ごとに別々のシステムを持つ場合と違い、ある業務での入力がそのまま他の業務に反映される。

## 成り立ち

ERPは製造業の生産計画の手法から発展した。

| 時代 | 名称 | 何を計画・管理したか |
|---|---|---|
| 1960〜70年代 | MRP（資材所要量計画） | 生産計画と部品表（BOM）から、必要な資材の量と時期を計算する |
| 1980年代 | MRP II（製造資源計画） | 資材に加え、設備の能力・人員・原価まで含めて計画する |
| 1990年代〜 | ERP | 製造以外（会計・販売・人事など）も含め、全社の業務を1つのシステムに統合する |
| 2010年代〜 | クラウドERP | ベンダーが基盤と更新を管理するサービスとして提供される（→ 03章） |

各方式の詳しい対比は [付録A](../appendix/A_erp-market-overview.md) を参照。

## 統合がもたらすもの

- **一度の入力が全業務に反映される**：出荷を登録すると、在庫が減り、売上が計上され、会計の仕訳が自動で作られる。
- **取引データの「正」が1つになる**：同じ数字が部門ごとに食い違わない。
- **業務の標準化**：パッケージに組み込まれた業務手順（ベストプラクティス）に合わせることで、拠点や部門をまたいで業務がそろう。

## 範囲（何であり、何でないか）

| ERPが扱うもの | ERPが扱わないもの（隣接領域） |
|---|---|
| 財務会計・管理会計（原価計算を含む） | 製造の実行：作業指示、秤量、電子バッチ記録（MES） |
| 販売（受注・出荷・請求） | 顧客との活動：訪問、面談、販促（CRM） |
| 購買・在庫 | 品質・薬事の文書と記録：逸脱、CAPA、承認申請（QMS・RIM） |
| 生産計画・製造指図・実績の受け取り | 分析・可視化の基盤（DWH・BI） |
| 品質・保全の基本機能（製品による） | 人事の詳細（HCM。製品によってはERPに含む） |

境界は製品ごとに異なり、重なる部分もある。境界の詳細は [function-allocation](../../../cross-cutting/function-allocation/function-allocation.md) を参照。
