# erp — ERP（統合基幹業務システム）

**一言でいうと**：会計・販売・購買・在庫・生産などの基幹業務を、1つのデータベースで統合して処理するパッケージソフトウェア。

- **扱うこと**：ERPの定義と歴史、構造（モジュール、設定とアドオン、テンプレート、Clean Core）、主要製品と提供形態、ERPに本質的に伴う論点、隣接領域との境界
- **扱わないこと**：選定の判断、個別製品の導入・設定の手順
- 当社の現状は 06章にだけ書く

## 読み方

- 隣接領域との境界（どのシステムが何を持つか）は [function-allocation](../../cross-cutting/function-allocation/function-allocation.md) にまとめている。
- 01 → 02 → 03 → 04 → 05 の順に読む。04 は、懸念や要望を聞いたときに、それがどの軸の話かを引くための章。
- 正本は `chapters/` と `appendix/` の Markdown。
- 出典と確認日は各章末に記載。「要確認」は裏付けが取れていない記述。
