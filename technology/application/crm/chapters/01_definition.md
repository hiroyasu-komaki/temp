# 01 営業・マーケティング（CRM）の定義と範囲

## 要旨

CRM（Customer Relationship Management）は、**顧客との関係と活動を記録し、計画し、次の働きかけにつなげる**ための仕組みである。製薬企業の CRM は、顧客が医療従事者（HCP）と医療機関（HCO）であること、販促の資材と活動が規制で縛られることが、一般の CRM と違う。

## 用語

| 用語 | 意味 |
|---|---|
| HCP（Healthcare Professional） | 医師・薬剤師などの医療従事者 |
| HCO（Healthcare Organization） | 病院・診療所・薬局などの医療機関 |
| MR（医薬情報担当者） | 医療従事者に医薬品の情報を提供する営業の担当者 |
| MSL（Medical Science Liaison） | メディカル部門で、医学・科学の観点から医療従事者と情報を交換する担当者 |
| コール（訪問記録） | MR が医療従事者に会った記録。話した製品・使った資材・次の予定 |
| MLR 審査 | 販促資材を、医学（Medical）・法務（Legal）・薬事（Regulatory）の三者で事前に審査すること |
| オムニチャネル | 対面・メール・Web 講演会など複数の経路を組み合わせて、医療従事者に働きかけること |

## 日本の規制

厚生労働省は2018年9月25日に「医療用医薬品の販売情報提供活動に関するガイドライン」を公表し、2019年4月1日から適用した。口頭説明など証拠が残りにくい行為や、不適正な使用を助長しかねない行為への懸念が背景にある。製薬企業には、販売情報提供活動を監督する部門の設置などが求められている。CRM は、活動と使った資材の記録を残す仕組みとして、この対応と結びつく（本資料の整理）。
