- **扱うこと**：製薬企業の CRM の用語、日本の販売情報提供活動ガイドライン、顧客マスタ・活動・資材を中心にした構造、主要製品と Veeva・Salesforce の分離、論点、隣接領域との境界
- **扱わないこと**：Veeva 製品の詳細（→ veeva-platform 付録C・G）、受注・請求（→ erp）
- 当社固有の情報は 06章にだけ書く（未作成）
