# epm — 経営管理（EPM）

**一言でいうと**：予算・計画を立て、実績と比べ、決算・連結をまとめて報告するための仕組み。

- **扱うこと**：EPM の定義と用語（FP&A、連結、管理会計、配賦）、計画と決算・連結の流れ、主要製品（財務計画、決算・連結、国内の製品、ERP 付属の機能）、論点、隣接領域との境界
- **扱わないこと**：日々の取引と仕訳（→ erp）、全社の分析基盤（→ analytics）
- 当社固有の情報は 06章にだけ書く（未作成）
