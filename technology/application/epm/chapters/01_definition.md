# 01 経営管理（EPM）の定義と範囲

## 要旨

経営管理（EPM：Enterprise Performance Management）は、**予算・計画を立て、実績と比べ、決算をまとめて報告する**ための仕組みである。ERP が日々の取引を記録するのに対し、EPM はその結果を集めて、計画との差や会社全体の数字を扱う。Gartner は市場を「財務計画」と「決算・連結」の2つに分けて評価している。

## 用語

| 用語 | 意味 |
|---|---|
| FP&A（Financial Planning & Analysis） | 予算編成、見込み（フォーキャスト）、実績との差異分析を行う業務 |
| ドライバーベース計画 | 売上数量・単価・人員数など、数字を動かす要因（ドライバー）から計画を組み立てる方法 |
| ローリングフォーキャスト | 年度の区切りにとらわれず、一定期間先までの見込みを定期的に更新する方法 |
| 連結決算 | グループ会社の財務諸表を合算し、グループ内の取引や債権債務を消去して、グループ全体の財務諸表を作る |
| 内部取引消去 | 連結の際に、グループ会社同士の売買・貸借を相殺すること |
| 管理会計 | 社内の意思決定のための会計。部門別・製品別の損益、費用の配賦など |
| 配賦 | 共通費（本社費・IT費など）を、一定の基準で部門や製品に割り振ること |

## 扱うもの・扱わないもの

| 扱う | 扱わない（→ 移り先） |
|---|---|
| 予算・計画・見込み、差異分析 | 日々の取引と会計仕訳（→ erp） |
| 決算・連結、開示用の資料作成 | 全社の分析基盤・BI（→ analytics） |
| 管理会計の集計と配賦 | 人件費の元になる人事情報（→ hcm） |
| 主要製品、論点、隣接領域との境界 | 勘定科目・組織のマスタの正本の決め方（→ master-data） |
