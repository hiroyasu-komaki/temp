# hcm — 人事（HCM）

**一言でいうと**：従業員と組織の情報を持ち、給与・勤怠・人材の管理を行う仕組み。「誰が、どの組織に、どの立場でいるか」の正本。

- **扱うこと**：HCM の機能の区分、コア人事を中心にした構造、日本の制度に合わせた処理、主要製品（グローバルのスイート、国内の製品）、論点、隣接領域との境界
- **扱わないこと**：ID と権限の付与（→ identity）、人件費の計画（→ epm）、給与の会計仕訳（→ erp）
- 当社固有の情報は 06章にだけ書く（未作成）
