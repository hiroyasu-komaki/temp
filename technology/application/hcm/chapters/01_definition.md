# 01 人事（HCM）の定義と範囲

## 要旨

人事（HCM：Human Capital Management）のシステムは、**従業員と組織の情報を持ち、給与・勤怠・人材の管理を行う**。会社の中で「誰が、どの組織に、どの立場でいるか」の正本であり、ID の発行（identity）や原価計算（erp）の元になる。日本では、年末調整や社会保険の手続きなど、国ごとの制度に合わせた処理が多い。

## 機能の区分

| 区分 | 内容 |
|---|---|
| コア人事 | 従業員の基本情報、所属・役職・等級、組織の階層、入社・異動・退職の記録 |
| 給与 | 給与・賞与の計算、社会保険・税の控除、年末調整、明細の配布 |
| 勤怠 | 出退勤、休暇、残業の管理。フレックス・裁量労働などの勤務形態 |
| タレントマネジメント | 評価、目標、育成、後継者、スキル |
| 採用・オンボーディング | 応募者の管理、入社手続き |
| 労務手続き | 社会保険・雇用保険の届出（日本では e-Gov による電子申請がある） |

## 扱うもの・扱わないもの

| 扱う | 扱わない（→ 移り先） |
|---|---|
| 上の機能の区分と、システムの構成 | ID とアクセス権の付与（→ identity） |
| 主要製品（グローバルのスイート、国内の製品） | 人件費の計画（→ epm） |
| 論点と隣接領域との境界 | 給与の会計仕訳と原価計算（→ erp） |
