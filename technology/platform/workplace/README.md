# workplace — ワークプレイス

**一言でいうと**：社員が毎日使う端末と、メール・会議・チャット・文書共有のコラボレーション基盤、それらを配り・更新し・守る端末管理の領域。

- **扱うこと**：3つの要素（端末、コラボレーション基盤、端末管理）、成り立ち（Microsoft 365・Google Workspace・Windows 365・Copilot・Teams の切り離し・Windows 10 のサポート終了）、提供形態、更新とライセンス、主要製品、論点、隣接領域との境界
- **扱わないこと**：ID とログインの基盤（→ identity）、EDR による検知と対応（→ security-operations）、サービスデスクの運用（→ it-operations）、生成 AI の仕組みとリスク（→ ai）、Power Platform などでアプリを作る仕組みと統制（→ app-development）
- 当社固有の情報は 06章にだけ書く（未作成）
