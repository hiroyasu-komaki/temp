# it-operations — IT運用

**一言でいうと**：作り終えたシステムを止めずに動かし続け、利用者の依頼と問い合わせに応え、変更を安全に入れる日々の活動。

- **扱うこと**：4つの領域（ITSM、監視、ジョブ管理、バックアップ）、成り立ち（SRE、ITIL 4、AI Applications in ITSM）、ITIL 4 のプラクティス、SLO とエラーバジェット、3-2-1 ルール、主要製品、論点、隣接領域との境界
- **扱わないこと**：攻撃の検知と対応（→ security-operations）、基盤の設計（→ infrastructure）、端末そのもの（→ workplace）
- 当社固有の情報は 06章にだけ書く（未作成）
