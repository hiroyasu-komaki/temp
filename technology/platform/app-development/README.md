# app-development — アプリ開発・DevOps・ローコード

**一言でいうと**：自社でソフトウェアを作り、変え、届け続けるための工程と仕組み。専門の開発者による開発（自社開発・パッケージの拡張）と、業務部門の担当者がローコードで作る開発（市民開発）の両方を扱う。

- **扱うこと**：開発・DevOps・CI/CD・DevSecOps・ローコード・市民開発の用語、開発の成果の指標（DORA）、安全な開発の枠組み（NIST SSDF）、開発のライフサイクルとパイプライン、環境の分け方、ローコードの統制の仕組み、AI による開発の支援、主要製品、論点、隣接領域との境界
- **扱わないこと**：Web アプリの脅威と設計原則・認証・認可（→ [web-security](../../cross-cutting/web-security/README.md)）、本番の運用（→ [it-operations](../it-operations/README.md)）、GxP のシステムのバリデーションの要件（→ [gxp-compliance](../../cross-cutting/gxp-compliance/README.md)）、市民開発の社内ルール（→ governance 側、未作成）
- 当社固有の情報は 06章にだけ書く（未作成）
