# ai — AI（生成 AI・LLM・AI エージェント）

**一言でいうと**：文章・画像・コードを生成する AI と、その中心の大規模言語モデル、道具を使って作業を進める AI エージェントの仕組みとリスク。

- **扱うこと**：用語の定義、成り立ち（Transformer → RAG → ChatGPT → NIST AI RMF → EU AI 法 → MCP → 日本の AI 法）、4層の構成、RAG、AI エージェントと MCP、AI に固有のリスク（OWASP LLM Top 10、NIST AI 600-1）、提供形態と基盤、論点、隣接領域との境界
- **扱わないこと**：AI の利用に関する社内のルールと体制（→ governance/ai-security-framework）、GPU などの計算基盤（→ infrastructure）、Copilot のライセンスと配布（→ workplace）
- 当社固有の情報は 06章にだけ書く（未作成）
