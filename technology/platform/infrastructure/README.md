# infrastructure — クラウド・インフラ

**一言でいうと**：業務アプリケーションとデータが動くための計算資源・保存領域・ネットワーク・データベースを、オンプレミスまたはクラウドで提供する層。

- **扱うこと**：クラウドの定義（NIST SP 800-145）と成り立ち、サービスモデルと責任共有モデル、ランディングゾーン、Well-Architected Framework、FinOps、主要なクラウド事業者、ガバメントクラウド、VMware の契約変更、論点、隣接領域との境界
- **扱わないこと**：SaaS の業務アプリそのもの（→ 各業務アプリのトピック）、監視・障害対応・バックアップの運用（→ it-operations）、データ連携（→ integration）
- 当社固有の情報は 06章にだけ書く（未作成）
