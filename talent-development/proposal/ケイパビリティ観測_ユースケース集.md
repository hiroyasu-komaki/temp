# ケイパビリティ観測のユースケース集

ジョブロール別ケイパビリティ観測は、SWPのステップ6「進捗のモニタリング」として設計されたものです。しかし、そこで可視化される「要求ケイパビリティと実際のずれ」は、観測そのものの目的を超えて、他の担当者の判断材料になります。

この文書は、観測の結果を**誰が、どう使えるか**を担当者ごとにまとめたものです。観測計画そのものについては「ジョブロール別 ケイパビリティ観測計画（骨格）」を参照してください。

# ユースケース1　採用担当者：ヘッドカウント計画への活用

## 1. 何が新しく分かるようになるか

ヘッドカウント計画は、これまで**頭数**の話でした。この観測が足すのは、**その頭数が要求水準に届くのかどうか、届くとすればいつか**という情報です。

| | これまでの見え方 | この観測が足すもの |
|---|---|---|
| 人数 | 必要人数と現在人数の差 | 現在の人数のうち、期限までに要求水準へ届く人が何人か |
| 時期 | いつまでに何人 | いつ頃、誰が要求水準に届くか。届かないと分かるのはいつか |
| 水準 | 職種と等級 | 要求水準に対して、どれだけ足りないか（あるいは超えているか） |
| 打ち手 | 採用するかしないか | 育成で埋まる分と、採用でしか埋まらない分の切り分け |

### いちばん大きい変化：「頭数は足りているのに能力が足りない」が見える

ある職種×担当領域に5名いるとします。頭数の計画では「不足ゼロ」です。

しかし観測の結果、期限までに3名は要求水準（100）を超える見込みで、残る2名は飽和カーブの上限が85付近にあり、投資を続けても届かないことが分かったとします。このとき実質的に欠けているのは**2名分の能力**です。

従来の数え方ではこれが「不足ゼロ」と出てしまいます。この観測は、そのずれを人数として言える形にします。

---

## 2. ヘッドカウント計画の4つの判断に、どう効くか

### 2.1 どれだけ採るか

採用で埋めるべき数は、次の引き算で出ます。

> **必要人数 −（期限までに要求水準へ届く見込みの人数）= 採用で埋める数**

これまでの「必要人数 − 現在人数」との違いは、現在人数を頭数ではなく**到達見込み**で数える点です。

### 2.2 いつ動き出すか

観測からは、その人がいつ頃要求水準に届くかの見込みが出ます。逆に言えば、**届かないと分かる時期**も早めに出ます。

そこから採用のリードタイム（募集・選考・入社・立ち上がり）を逆算して、動き出す時期を決めます。「Q6には間に合わない」がQ2の時点で分かれば、4四半期の猶予があります。

### 2.3 どの水準の人を採るか

飽和カーブの上限と要求水準の差が、そのまま採用で求める水準になります。

| 状態 | 求める水準 |
|---|---|
| 上限が要求水準にわずかに届かない | 要求水準（レベル3）を満たす人を必要数 |
| 上限と要求水準の差が大きい | レベル4〜5相当。1名で周囲の水準を押し上げられる人を狙う |
| 創発型を狙った領域なのに、実測が飽和カーブに収まっている | レベル5相当。起点になる人がいない状態なので、頭数を足しても変わらない可能性がある |

観測の採点表では、レベル4・5は「担当範囲を超えて他の案件・他のメンバーに影響が及んだ」状態として定義されています。採用の要件定義でも、同じ言葉で水準を伝えられます。

### 2.4 採らない、という判断

要求水準に到達済み、または到達の見込みが立っている領域では、採用しません。

採用も投資です。要求を超えた分の人員は、育成の過剰投資と同じ性質の無駄になります。この観測は、「念のためもう1名」を止める根拠になります。

---

## 3. Buy と Borrow の使い分け

観測は、不足が**一時的なもの**か**構造的なもの**かを区別します。この区別が、採用と外部活用の選び分けに直結します。

| 観測が示す状態 | 打つ手 | 理由 |
|---|---|---|
| 育成は進んでいるが、要求水準への到達が期限に間に合わない | **Borrow**（外部活用） | 不足は一時的。到達したら外部を外せる。採用すると、その後に余剰になる |
| 飽和カーブの上限が、要求水準に届かない | **Buy**（採用） | 構造的に届かない。時間をかけても解決しない |
| 創発型を狙った領域が、飽和カーブに収まっている | **Buy**（レベル4〜5相当） | 起点になる人がいない。育成の設計を変えるだけでは動かない可能性がある |
| 要求水準に到達済み、または到達見込みあり | **採らない** | 過剰になる |

「足りないから採る」ではなく、「**時間で解決するのか、しないのか**」で分ける、という考え方です。
