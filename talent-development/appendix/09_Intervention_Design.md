# 打ち手の設計 ── 差分が出た後、現場は何をするのか

> 本資料は、年次戦略（→ HTML 05）が出力した差分を、**実行可能な作業に変換する**段階にあたる。
>
> 結論を先に置く ── **能力は、人を訓練して上げるのではない。仕事の側を変えて上げる。**
> したがって打ち手の単位は個人ではなく、**業務プロセスと様式**である。
>
> ただし、行動を要求するだけでは足りない ── **予測と結果を突き合わせなければ、形ばかりの実行になる。**
> A1〜A5 はいずれも予測と結果の対でできており、**突合の工程を欠いたまま実行しても、翌年も同じ精度で外れ続ける。**
>
> そしてもう一つ ── **打ち手には作動条件がある。**
> 機会・失敗の許容・時間・移転の動機。この4つが満たされなければ、
> **測定設計がどれだけ正確でも、行動は発生せず、翌年も同じ値が出力される。**

---

## 0. なぜ、この資料が必要なのか

### 精度が、片側に偏っている

本フレームワークが測定側に与えているものを数え上げると、次のようになる。

三層構造（基層・付加層A・付加層B）／仲介機能の5項目（A1〜A5）／行動で書かれた3水準の判定基準／証拠の三段階／未検証フラグ／アンカー事例による拠点間較正／記入できる様式2点／架空の記入例。

対して打ち手側に与えられているもの ──

**「育成／採用／配置」の3語と、優先順位表（P1〜P4）の打ち手欄1行。**

> **診断の解像度と、処方の解像度が釣り合っていない。**

この非対称は、読み手の階層によって現れ方が違う。

| 読み手 | 本フレームワークが渡すもの | 十分か |
|---|---|---|
| **組織責任者・上位マネジャー** | 需給の差分。どこに人と予算を当てるかの判断材料 | **十分である。** 差分が出れば意思決定はできる |
| **中間以下のマネジャー・タレントデベロップメント担当** | 「この領域は所管のみ・検証済でした。1年で評価できるに上げてください」 | **不十分である。** これは指示ではなく、結果の通知である |

**上位レイヤにとって完成している資料が、実行レイヤにとっては未着手である。** 本資料はその欠落を埋める。

### さらに、自己言及の問題がある

より深刻な問題がある。本フレームワークは、外部知識の吸収能力が内部の既存知識に規定されることを前提に置いている（→ HTML 05、Cohen & Levinthal 1990）。この命題を素直に適用すると、次の帰結が出る。

> **「所管しているのみ」の状態にある組織は、そこから抜け出す計画を、自力で設計できない。**

育成計画を書けと指示された課長が、まさにその領域で所管のみだった場合、彼は何を根拠に計画を書くのか。技術的な当否を判断できないからこそ「所管のみ」と判定されたのであり、その人に「どう育成するか」を設計させるのは、判定内容と矛盾する。

**本資料の打ち手が「計画を書く」形ではなく「様式を変える」形を取るのは、この帰結への対処である。**
技術的な当否を判断できない管理職でも、**稟議様式に欄を1つ足すことはできる**。制度の改訂は、能力水準に依存しない。

## 1. 立場 ── 能力は、仕事の側を変えて上げる

本フレームワークの測定設計は「できるか」ではなく「したか」を問う（→ HTML 04・様式2）。この問いの立て方は、打ち手の形を一意に決めてしまう。

| 測定が問うもの | 打ち手が変えるもの |
|---|---|
| 能力（できるか） | → 人（訓練する） |
| **行動（したか）** | → **仕事（させる）** |

痕跡は、能力からではなく**行動**から生まれる。そして行動が発生するかどうかは、多くの場合その人の資質ではなく、**置かれた役割がその行動を要求しているかどうか**で決まる。HTML 04 が「測定が個人の資質評価から切り離される」としているのは、この意味においてである。

> **したがって、打ち手の単位は個人ではない。業務プロセスと様式である。**

この立場は、研修体系や学習プログラムを否定するものではない。ただし本フレームワークの中では、それらは**主たる打ち手ではなく、補助**に置かれる。理由は単純で、**研修では痕跡が生まれないからである。** 受講記録は、外部成果物を独立に検証した証拠にならない。

### 既存記述との対応

この立場は新規のものではない。HTML 05 の優先順位表 P1 の打ち手欄に、既に畳み込まれている。

> P1 ／ R4が「所管のみ・検証済み」のセル ／ 打ち手：**育成（A2〜A4の行動を業務に組み込む）**

「業務に組み込む」が指しているのは、まさに業務プロセスの改訂である。**本資料は、この括弧の中身を展開したものにあたる。**

## 2. A1〜A5 を、業務プロセスに組み込む

以下の5点が、打ち手の中核である。いずれも**制度改訂であり、費用はほぼ発生しない。** 発生するのは工数である（→ 4節 作動条件③）。

### A1 要件の翻訳

| | |
|---|---|
| **現状（想定）** | 要件定義書・RFPをベンダーが下書きし、社員が確認・承認する |
| **改訂** | **初稿の執筆者を社員に固定する。** ベンダーは初稿に対するレビュー側に回す |
| **生まれる痕跡** | 要件定義書・RFP・仕様書の執筆者欄 |
| **抵抗** | 小。初稿の品質は落ちるが、レビューで回復する |

### A2 工数妥当性の検証

| | |
|---|---|
| **現状（想定）** | ベンダー見積を稟議にそのまま転記する |
| **改訂** | 稟議様式に **「自社積算」欄を新設**する。ベンダー見積の提示**前**に社員が積算し、両者の差分と、差分が生じた理由を記載する。**空欄では回付できない** |
| **生まれる痕跡** | 稟議・予算における工数積算の主体 |
| **抵抗** | 中。「積算できないから困っている」という反発が出る |

> **精度は問わない。外れてよい。**
> 外れた理由を書くことが能力を作るのであって、当てることが目的ではない。ここを取り違えて精度を評価対象にすると、社員はベンダーに事前に数字を聞いてから欄を埋めるようになり、**様式だけが残って行動が消える。**

### A3 成果物の受入判断

| | |
|---|---|
| **現状（想定）** | 検収印のみ。差し戻しの記録が存在しない |
| **改訂** | 検収記録に **「差し戻し検討結果」欄**を置く。差し戻さない場合も、**何を確認し、なぜ差し戻さないと判断したか**を記載する |
| **生まれる痕跡** | 検収記録／差し戻し・修正要求の記録 |
| **抵抗** | 中。検収が形式手続きから判断行為に変わるため、所要時間が延びる |

### A4 代替案の提示

| | |
|---|---|
| **現状（想定）** | ベンダー提案書のみが保管されている |
| **改訂** | 一定金額以上の案件は、**ベンダー提案とは別の選択肢を1つ添えなければ決裁に上げられない**。「現行踏襲」「見送り」も選択肢として認める |
| **生まれる痕跡** | 設計方針の検討記録・比較検討資料 |
| **抵抗** | **大。** 決裁の要件そのものを変えるため、意思決定の速度に影響する |

> **A4は5項目の中で最も強い証拠であり、同時に最も抵抗が大きい。**
> HTML 04 が指摘する通り、A1〜A3は「求められたから応じた」でも成立するが、代替案の提示は**求められていないのに自ら行う行動**である。したがって、制度が要求しなければ発生しない。**逆に、制度が要求すれば発生する。**

### A5 障害時の切り分け判断

| | |
|---|---|
| **現状（想定）** | インシデント記録の一次切り分け実施者がベンダー名で埋まっている |
| **改訂** | 一次切り分けの**実施者欄を必須化**し、ベンダーへエスカレーションする前に、社員が**最初の切り分け仮説**を記載する |
| **生まれる痕跡** | インシデント記録における一次切り分けの実施者 |
| **抵抗** | 中。障害時に手順が1段増えるため、初動の遅れが懸念される |

> 仮説は外れてよい。**外れた仮説の記録は、正しい仮説の記録と同じだけ、判断が行われた証拠になる。**

### 副次的な効果 ── P4が同時に解ける

上記5点はいずれも**様式の改訂**である。したがって、実行すると自動的に記録運用が整備される。

> **P1（劣化の解消）への打ち手が、そのままP4（未検証の解消）への打ち手になっている。**
> HTML 05 は「P4は他の3つとは種類が違う／初年度においてはP1〜P3と並行して進める必要がある」としているが、**並行ではなく同一の作業である。** 様式に欄が増えれば、翌年の照会先はその欄になる。

## 3. 突合 ── 実行を、学習に変える

### A1〜A5 は、そもそも予測と結果の対でできている

2節の打ち手は、いずれも**予測を記録させる**ところで止まっている。自ら積算した工数、差し戻さないと判断した理由、最初の切り分け仮説 ── これらはすべて、**後から結果が判明する**種類の記録である。

| | 予測（行動時に記録する） | 結果（後から判明する） | 突合の時点 |
|---|---|---|---|
| **A1** 要件の翻訳 | 自ら書いた要件 | 実装段階の手戻り・仕様変更 | 検収時 |
| **A2** 工数妥当性の検証 | 自社積算値 | ベンダー見積／**実績工数** | 見積受領時／案件完了時 |
| **A3** 成果物の受入判断 | 差し戻す／差し戻さない判断と、その理由 | 稼働後の障害・不具合 | 稼働3か月後 |
| **A4** 代替案の提示 | 提示した選択肢 | 採否と、その理由 | 決裁時 |
| **A5** 障害時の切り分け判断 | 一次切り分け仮説 | 確定した原因 | 復旧時 |

> **5項目すべてが対になっているのに、突き合わせる工程がどこにもない。**
> これが「形ばかりの実行」の正体である。積算欄を埋めても実績と照合しなければ、**翌年も同じ精度で外れ続ける。**

本資料は既に2節で「精度は問わない。外れてよい。**外れた理由を書くことが能力を作る**」（A2）、「**外れた仮説の記録は、正しい仮説の記録と同じだけ、判断が行われた証拠になる**」（A5）と書いている。**その理由を書く機会が、どこにも設計されていなかった。**

### 手当て ── 各様式に「突合欄」を1つ足す

打ち手の性格は変わらない。2節と同じく、**様式の改訂**である。

| 項目 | 追加する欄 | 記入する時点 |
|---|---|---|
| **A1** | 手戻りの件数と、要件のどの記述が原因だったか | 検収時 |
| **A2** | **実績工数との差分と、その理由** | 案件完了時 |
| **A3** | 稼働後に発生した不具合と、検収で見るべきだった観点 | 稼働3か月後 |
| **A4** | 提示した代替案の採否と、判断を分けた基準 | 決裁時 |
| **A5** | 確定原因と、初期仮説との差 | 復旧時 |

> 記入するのは**「当たったか」ではなく「なぜ外れたか」**である。
> 当否のみを記録すれば、それは精度の評価になる。2節A2の注意書き ── 精度を評価対象にすると、社員はベンダーに事前に数字を聞いてから欄を埋めるようになる ── が、そのまま当てはまる。

### 突合の記録は、水準判定の証拠になる

副次的な効果として、突合記録は測定側にも効く。

> **「なぜ外れたか」を分解して書けているかどうかは、水準の強い証拠である。**

外した理由を分解できる者は、その領域を評価できている。分解できない者は、欄を埋めただけである。A4（代替案の提示）が「求められていないのに自ら行う」という強さを持つのに対し、突合記録は「**自らの判断の誤りを分解できる**」という別種の強さを持つ。証拠の三段階（→ HTML 04）における**二次証拠**にあたる ── 事後に作れない自筆の成果物だからである。

### 継承の順序 ── 「継承してから実行」は成立しない

実行を支える知識やノウハウの継承が要る、という指摘は正しい。ただし**順序を誤ると、デッドロックする。**

継承すべきノウハウを、いま社内の誰が持っているのか。工数の読み方も、検収で見るべき観点も、**相当部分はベンダー側にある**。「所管しているのみ」に落ちているとは、そういう状態である。継承を実行の前提条件に置けば、**継承元が存在しない** ── 0節の自己言及の問題と、まったく同じ構造である。

> **知識は行動に先行しなくてよい。ただし行動の直後に来なければならない。**
> そして**突合記録の蓄積が、最初の継承物になる。**

この設計において、「見積が外れた理由をベンダーに聞く」は**正当な学習行為**である。A2の突合として最短経路であり、聞いた内容が記録に残れば、それが次の担当者への継承物になる。**継承物を外から調達するのではなく、突合が生成する。**

### 研修の位置づけ ── 無効なのではなく、順序である

1節で「研修では痕跡が生まれない」として補助に置いたが、これは範囲の切り分けが粗かった。分けるべきである。

| | 範囲 |
|---|---|
| 研修**コンテンツ**の内容設計（何を教えるか） | **範囲外** |
| 研修の**対象を決める手続き**（誰に何が足りないか） | **範囲内。突合がこれを出力する** |

これは本フレームワークが年次レベルで既に述べていることと、同型である。

> Year 1 に育成目標を置かないのは、この年の測定が「未検証」を大量に含み、**どこを育てるべきかが確定していない**ためである。ここで見切り発車すれば、5年前と同じく実態からずれた対象に投資することになる。（→ HTML 05）

**同じ論理が、個人レベルにも適用される。** 突合で「何が分からなかったか」が特定される前の研修は、実態からずれた対象への投資になる。**研修が無効なのではなく、順序の問題である。**

### 頻度 ── 全件は不可能である

突合は追加工数を伴う。全案件で行えば回らない。**作動条件①（機会の配分）で選んだ案件に限る**（→ 4節）。A2・A4の対象として選んだ案件が、そのまま突合の対象になる ── **選定は一度でよい。**

## 4. 作動条件 ── これが満たされなければ、何も起きない

2節の制度改訂は、**それだけでは作動しない。** 以下の4条件が前提になる。

### 条件① 機会の配分

「評価できる」に上がるには、評価する機会が要る。しかし機会 ── **差し戻せる案件、代替案を出せる意思決定** ── は希少財であり、現状ではその大半がベンダー側にある。

| 決めること | 決めないとどうなるか |
|---|---|
| 年間の案件のうち、**何件をA2・A4の対象にするか** | 全件を対象にすると回らず、件数を決めなければ1件も実施されない |
| その案件を、**誰に割り当てるか** | 手の空いている人に回り、育成対象と一致しない |

> **全件は不可能である。** 機会は有限であり、配分は判断である。ここを決めずに「A2〜A4を業務に組み込む」と指示すれば、現場は組み込む対象を持たない。

なお、ここで選んだ案件が、そのまま**突合（→ 3節）の対象**になる。選定は一度でよい。

### 条件② 失敗の許容

A3（差し戻し）とA4（代替案の提示）は、**間違えうる行為**である。

差し戻した結果、実は問題がなく、工期が2週間延びた ── このとき担当者がどう扱われるか。ここが定まっていない組織では、**痕跡は永久に発生しない。** 差し戻さないことが常に安全であり、合理的な選択になるからである。

> **測定設計がどれだけ正確でも、行動が起きなければ、毎年同じ値が出力される。**
> 「所管のみ」が改善しない原因が、能力ではなく**この条件の不在**である可能性を、常に疑う必要がある。

**明文化すべき一文がある。**

> 差し戻し・代替案の提示を行ったこと自体は、結果の当否にかかわらず、評価を下げない。

これを文書に落とさなければ、条件②は満たされたことにならない。口頭の保証は、次の人事異動で消える。

### 条件③ 時間

日常業務は回り続けている。A2（自ら積算する）は、**純粋な追加工数**である。

| 決めること | 決めないとどうなるか |
|---|---|
| 1案件あたり、A2・A4に**何時間を見込むか** | 見込まないまま指示すれば、残業か、形式的な記入のどちらかになる |
| その時間を、**誰の業務時間から取るか** | 取り先を決めなければ、担当者個人が吸収する |

> 時間を確保せずに様式だけ変えると、現場は**痕跡を作るための作業**を始める。虚偽ではない ── 欄を埋めるために、ベンダーに数字を聞いて記入する。**行動なき痕跡**が生まれ、測定は再び実態からずれる。**5年前と同じ形の失敗である。**

### 条件④ 移転の動機（P2に固有）

P2（経緯知識の複数名化）は、他の3つと性質が違う。**移転する側の意思を必要とする。**

20年その領域を支えてきた社員にとって、経緯知識の移転は、**自らの代替可能性を高める行為**でもある。組織にとっての価値と、本人にとっての利害が、この一点で逆を向く。

本フレームワークは処遇制度を「課題に含まれないもの」としている（→ HTML 01）。その切り分け自体は正しい。しかし、

> **移転が本人の不利益にならないという保証がない限り、P2は実行されない。**

これは打ち手の問題ではなく、**打ち手の前提条件**である。範囲外に置いたまま P2 を計画に載せることはできない、という事実だけは記録しておく必要がある。

### 作動条件の診断

計画を立てる前に、次の質問に答えられるかを確認する。答えられなければ、その領域では打ち手が作動しない。

1. 直近1年で、社員が検収を差し戻した案件は何件あるか。**0件の場合、それは品質が高かったからか、差し戻せなかったからか**
2. 差し戻した担当者は、その後どう扱われたか
3. ベンダー見積を、社員が独立に積算し直した案件は何件あるか
4. A2・A4に充てられる時間は、誰の予算・工数に計上されているか
5. 経緯知識の保有者が1名しかいない領域について、**移転を本人に依頼したことがあるか。断られたことはあるか**

## 5. 中間以下のマネジャーが、今日から着手できる3点

上位の意思決定を待たずに、自らの決裁権限の範囲で実行できるものに限る。

| # | 作業 | 所要 | 何が出来上がるか |
|---|---|---|---|
| **1** | 自部門の稟議様式に **「自社積算」欄**を足す | 様式改訂のみ | A2の痕跡が翌月から発生し始める |
| **2** | 検収時に **「なぜ差し戻さないか」を1行**書かせる | 運用の申し合わせのみ | A3の痕跡が発生する。同時にP4が解ける |
| **3** | 自部門の各システムについて、**経緯を照会できる社員の氏名を書き出す** | 半日 | **P2（不可逆な差分）の所在が判明する** |

> **3が最も緊急性が高い。**
> P1（評価水準の劣化）は回復可能である ── 制度を変えれば痕跡は生まれ始める。
> **P2（経緯知識の単一保有）は不可逆である** ── 退職した瞬間、採用でも配置でも戻らない。
> HTML 05 自身が「保有者の在籍期間が、計画の実質的な制約時間になる」としている通り、**期限が存在するのはP2の側だけである。**

## 6. R4先行 ≠ R4限定

様式2は初回の測定対象をR4（ベンダー統制）に絞っている。着手順序としては妥当である ── ①②③の分類を待たずに実行でき、判定が2値で軽い。

**ただし、R4に限定し続けることはできない。** 理由は2つある。

### (1) 「評価できる」は「遂行できる」に寄生している

A2（工数の妥当性判断）とA4（代替案の提示）は、**技術的判断を要求する。** 設計の代替案は、設計を知らなければ出せない。見積の当否は、作業内容を知らなければ判断できない。

したがって、

> **「評価できる」は独立した能力ではない。残存する遂行知識の上に成立している。**

R2・R3を放置してR4だけに投資すれば、遅れてR4も落ちる。これは本フレームワーク自身の吸収能力の議論（→ HTML 05）が予測することである。**R4のみを維持する定常状態は、存在しない。**

### (2) 誤読への備え

R4は、**ベンダー支出との接点**にある。R4の水準が上がれば、見積が締まり、差し戻しが増え、不要な機能が落ちる ── **財務効果が直接的で、測定可能で、早い。** R3（遂行能力）の向上は、効果が拡散的で遅い。

この非対称は避けられない。したがって、意図にかかわらず、

> **R4先行は「コスト削減施策」として読まれる可能性が高い。**

本フレームワークは「コスト削減にはならない」と明示しているが、その記述が守っているのは**相互カバー（人数が増えること）**であって、R4ではない。**R4は無防備である。**

**R4先行の理由を、統制ではなく認識の問題として述べ直しておく必要がある。**

> R4が「所管のみ」であるとき、組織は外部成果物の当否を判断できない。
> これは支出の問題である以前に、**組織が自らの状態を知覚できないという問題**である。
> 5年間、R4は測定項目に存在せず、一度も判定されていない ── 知覚が欠けていたのは、まさにこの領域であった。
> **R4を先に測るのは、知覚を回復するためである。**

### 広げる時点を、先に決めておく

| 契機 | 対象 |
|---|---|
| 初年度末（R4パイロット完了時点） | R2・R3へ測定項目を拡張。**様式は変えない。変わるのは測定項目だけである** |
| 2年目の測定 | R5を追加し、5ロールを揃える |

## 7. 様式2への追加 ── P2を初年度から可視化する

現状の様式2（記録照会シート）は、A1〜A5 の痕跡のみを照会する。この設計では、**P2は初年度の地図に載らない。** 付加層B（経緯知識）は全ロール横断であり、R4パイロットの視野に入らないためである。

**回復可能なP1を先に測り、回復不能なP2を1年待たせている。** これは順序の設計として弱い。

### 手当て ── 1列の追加

記録照会シートに、次の1列を足す。

| 追加する欄 | 記入内容 |
|---|---|
| **経緯照会可能者数** | この領域について、過去の経緯を照会できる社員は何名か（氏名を併記） |

ライン長は既に同じ記録群を参照しているため、**追加工数はほぼ発生しない。** これだけで Year 1 の成果物（地図）に P2 が載る。

> 判定は不要である。**人数と氏名を書くだけでよい。** 1名であれば、それがP2である。

## 8. 本資料が解かないこと

先に明示しておかなければ、後から失敗として扱われる。

| 解かないこと | 理由 |
|---|---|
| **個人の意欲・適性の差** | 本資料の打ち手は、行動を制度で要求する設計である。要求されても行わない場合の扱いは、人事の領域であり、本フレームワークの外側にある |
| **処遇制度との接続** | 条件④（移転の動機）は前提条件として指摘するに留まる。制度設計そのものは別のフレームワークが扱う |
| **案件が存在しない領域** | A2・A4は案件がなければ発生しない。案件数そのものが少ない領域では、この打ち手は作動しない。**配置または採用で埋めるほかない** |
| **記録運用の不在（P4）そのもの** | 2節の様式改訂は今後の記録を作るが、**過去3年分を遡って作ることはできない。** 初回測定の「未検証」は、この打ち手では消えない |
| **研修コンテンツの内容設計** | 何を教えるかは範囲外である。ただし**誰に何が足りないかを決める手続きは範囲内**であり、突合（→ 3節）がそれを出力する |
| **突合が生まない知識** | 突合は、自らの判断の誤りからしか学習を生まない。**一度も判断していない領域には、突合すべき対はない**。その領域は配置または採用で埋めるほかない |
