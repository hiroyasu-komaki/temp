# 2027年 予算起点の働きかけ（作業用）

第4章（`../../chapters/04_budget-driven-activity.md`）の進め方を、2027年度（2027年1月〜12月）に適用するための作業用フォルダ。正本は第4章で、このフォルダは年度ごとの段取り・未決事項・母集団ファイルを置く。

| ファイル | 内容 |
|---|---|
| `README.md` | このファイル（2027年の段取りと未決事項） |
| `vmo_population_FY2027_sample.xlsx` | 母集団ファイル。サンプル台帳で作成したもの。シートは 新規案件／ベンダー集計／ベンダー分析／施策マスタ（第4章 4.4） |

母集団ファイルは、黄色のセルが入力欄、灰色のセルが数式。

## 2027年に効いてくる条件

- 会計年度は暦年。FY2027予算は12月に確定し、確定後に予算台帳を固定する。
- ベンダー戦略は年次で、予算がある程度決まった時点で立てる。Tier1との来期会議もこの時期に行う。
- 2027-01-01に事業部門からの予算移管が実施され、移管された契約がGDSの管理に移る。

## 段取り（2026年11月〜2027年1月）

| 時期 | 作業 | 依存すること |
|---|---|---|
| 11月 | 目標の指標と測り方（第4章 4.3）を決める。ベンダー名の名寄せ規則と契約とのキーを決める。重要度の判定の進め方を決める。**依存度の判定の目安（ヒアリングの問い）をIT担当者との会議で合意する** | 調達部門・IT担当者との調整 |
| 11〜12月 | 新規案件（ベンダーが空欄・TBD・Various）を洗い出し、IT担当者・調達部門と選定の時期・アプローチ・目指す目標指標を握る。入力途中の予算台帳でベンダー集計とTierを仮に作る。ベンダー分析の行ごとに依存度をヒアリングする。Yellowの行は現場との合意を始める | 予算台帳への入力の進み具合、IT担当者の日程 |
| 12月 | 予算が確定したら母集団とTierを確定し、ベンダー戦略・3か年カレンダー・価値の見込みを作る。Redの行をIT戦略の所管へ上げる | FY2027予算の確定、予算移管の稟議 |
| 1月 | 移管された契約を加え、累計8割の線を引き直してTierと依存度を判定し直す。Tier1との来期会議を始める | 2027-01-01の一括移管 |

## 未決事項

1. 依存度の判定の目安（ヒアリングの問いと判断の基準）。IT担当者との会議で合意する
2. 4つの指標それぞれの目標値（水準）と、代わりの価値をどこまで金額に換算するか
3. 取引額が「小」で終期が確定しているベンダーの扱い（Tier3の定義は取引額「大」が前提のため、現状では重要度に従いTier2またはTier4になる）
4. 削減の当年度の基準を確定予算とすることでよいか（予算編成で織り込んだ削減との二重計上の防止）
5. ベンダー名の名寄せ規則と、予算の行と契約をつなぐキー
6. Redの行を上げる会議体・所管と、その基準・頻度
7. 調達部門との役割分担（交渉の主担当、発注・契約手続きの範囲）
8. 3か年の目標を誰が承認し、どの場で報告するか
