## FY2027に効いてくる条件

- 会計年度は暦年。FY2027予算は12月に確定し、確定後に予算台帳を固定する。
- 活動の対象期間は、FY2027〜FY2028の2年間とする（アンケートの時期の選択肢は2027 Q1〜2028 Q4）。
- アンケートは日本のメンバー向けに行う。予算はグローバル統合版のため、海外のベンダーも含まれる。まず日本で進め方の型をつくり、海外は、上位のベンダーと日本と共通のベンダーから、契約と更新時期を見える状態にしていく。海外での判断は、現地のIT担当者に残す。
- ベンダー戦略は年次で、予算がある程度決まった時点で立てる。Tier1との来期会議もこの時期に行う。
- 2027-01-01に事業部門からの予算移管が実施され、移管された契約がGDSの管理に移る。

## 段取り（2026年11月〜2027年1月）

| 時期 | 作業 | 調達部門との情報連携 |
|---|---|---|
| 11月初旬（準備） | 説明会で、取り組み候補とアンケートを説明する（`proposal/`） | M1：説明内容の事前共有（済） |
| 11月中旬（2週間） | アンケートを実施する。案件担当が、担当する行ごとに実施可否・時期・実施できない理由を答える。並行して、目標の指標と測り方（第4章 4.3）、ベンダー名の名寄せ規則と契約とのキー、重要度の判定の進め方を決める。新規案件（ベンダーが空欄・TBD・Various）を洗い出す | |
| 11月下旬 | 締め切り、回答をTier・契約区分ごとに取りまとめる | M2：回答の取りまとめ |
| 12月上旬〜中旬 | 案件担当と個別にやり取りし、シグナルと依存度を一緒に確かめ、施策と時期を案件ごとに合意する。新規案件は、選定の時期・アプローチ・目指す目標指標を握る | M3：合意結果と、調達部門と協働する案件 |
| 12月末 | 予算が確定したら母集団とTierを確定し、実行計画と目標値（合意した施策から積み上げ）をまとめる。案件ごとに「GDSで単独で行うこと」と「調達部門と協働すること」に分ける。Redの行をIT戦略の所管へ上げる | M4：実行計画 |
| 1月 | 移管された契約を加え、累計8割の線を引き直してTierと依存度を判定し直す。Tier1との来期会議を始める | |

## 未決事項

1. 12月のやり取りで使う依存度の判定の目安（第4章 4.4 ステップ4の問いと判断の基準）と、アンケートの「実施できない理由」から依存の型への読み替え（同ステップ3）。案件担当との会議で合意する
2. 区分ごとのシグナルの判定欄（R／A／G）の基準と、実行シグナル（Green／Yellow／Red）との関係
3. 4つの指標それぞれの目標値（水準）と、代わりの価値をどこまで金額に換算するか
4. 取引額が「小」で終期が確定しているベンダーの扱い（Tier3の定義は取引額「大」が前提のため、現状では重要度に従いTier2またはTier4になる）
5. 削減の当年度の基準を確定予算とすることでよいか（予算編成で織り込んだ削減との二重計上の防止）
6. ベンダー名の名寄せ規則と、予算の行と契約をつなぐキー
7. Redの行を上げる会議体・所管と、その基準・頻度
8. 調達部門との役割分担の確定（第1章 1.5.2の分担をたたき台に、`planning/vmo_purchasing-authority_check.xlsx` で確認し、第1章 1.5.4に反映する）
9. 実行計画と目標値を誰が承認し、どの場で報告するか
10. 母集団ファイル（サンプル）を第4章に合わせる：分析の単位を契約区分にそろえる（列「区分（a〜e）」の記号を外す）、アンケートの回答の列を加える、施策マスタを第4章 4.8のシナリオ・シグナル・打ち手に合わせる（Tierごとの打ち手の列は外す）
